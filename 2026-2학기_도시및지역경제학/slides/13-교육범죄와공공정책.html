학업성취도 = f(H, P, T, Z)

P 또래집단:학급 안의 급우

① 한계비용: 교사의 방과 후 시간의 기회비용

② 한계편익: 방과 후 수업 > 대학원 수강(거의 0)

③ 효율: 점 t(T*, $w_T$) · 점 g(G*, $w_G$), $w_G < w_T$

지출 불평등과 공공정책

전통적인 기금 원천: 지방재산세 → 학군 간 지출과 성취의 불평등

1970년대부터 재산세 기금의 합헌성 소송 (주 헌법: 교육은 시민의 근본적 권리)

주들이 개발한 평등의 세 개념

1. 적합성(adequacy):모든 학군이 주 전역의 최소 표준 이상의 교육 제공

2. 접근 평등성(access equality):모든 학군이 같은 실질과세표준에 접근
→ 같은 재산세율이면 학생 1명당 같은 수입

3. 교육 평등성(educational equality):모든 학군이 같은 수준의 교육 제공

→ 대부분의 주: 지출 불평등을 줄이는 데 초점 → 정부 간 교부금

정부 간 교부금: 기금계획(Foundation Plans)

재산세 과세표준이 낮은 학군에 더 큰 교부금

기금교부금 = 기금수준 − 기금세율 · L

L: 학생 1명당 지방재산가치(재산세 과세표준)

기금수준 5,000달러 · 기금세율 0.02 · L = 200,000달러

→ 교부금 = 5,000 − 0.02 × 200,000 = 1,000달러

L 이 1달러 높으면 교부금은 0.02달러 적음

지방세율에 따른 지출 (학생 1명당, 달러)

대응교부금: 보증된 과세표준

지방세 1달러마다 주가 m달러를 더함 → 교육의 기회비용 하락

대응교부금(matching grant)

1달러당 지방비용 = 1 / (1 + m)

m = 0.25 → 1 / 1.25 = 0.80달러

소득효과:실질소득 증가 → 교육 포함 정상재 지출 증가

대체효과:교육의 기회비용 1.00 → 0.80달러

→ 기금교부금보다 큰 자극효과

보증된 과세표준계획(GTB: guaranteed tax base plan)

GTB 교부금 = 지방세율 · (B − L)

B: 학생 1명당 보증된 과세표준 · L: 지방과세표준

L = 200,000 · B = 250,000달러

지방세율지방세입교부금교육지출
2%4,0001,0005,000
3%6,0001,5007,500

→ 1달러당 지방비용 = L / B
= 2,000 / 2,500 = 200,000 / 250,000 = 0.80달러

손실회피:얻은 1달러 g = 3유틸 · 잃은 1달러 l = 6유틸

① 점 s: +120달러 → 360유틸 · 점 f: −25달러 → −150유틸

② 기대효용 eu = 3/5 · 360 − 2/5 · 150 = 156유틸

③ 확실성 등가 CE = eu / g = 156 / 3 = 52달러 (점 u)

→ 바트는 범죄복권과 확실한 52달러가 무차별
합법적인 일로 52달러 이상 벌면 범죄 X

소득과 범죄행위

범죄의 CE > 합법적 임금(범죄의 기회비용)
→ 범죄가 합리적 선택

① 근로자 200명: 임금 1~100달러, 정수 임금마다 2명

② 합법적 임금선: 그 임금 이하를 받는 근로자 수
점 a: 16달러 이하 32명

③ 범죄의 CE = 52달러 수평선과 만나는 점 b
→ 임금 52달러 이하인 104명에게 범죄가 합리적

→ 범죄자 104명 · 합법적 근로자 96명

고뇌비용과 내적인 처벌 · 신경과학으로부터의 통찰

같은 편익과 비용을 마주해도 사람마다 선택이 다름

고뇌비용(anguish costs)과 내적인 처벌

이제까지: 쉽게 측정할 수 있는 비용과 편익만 고려

내적 처벌:범죄를 저지를 때 느끼는 고뇌
스스로 부과하고 확실함

바트 36유틸:eu 156 → 유틸 · CE 52 → 달러

→ 내적 처벌이 큰 대부분의 사람에게
범죄는 합리적 선택이 아님

신경과학으로부터의 통찰

전두엽 피질: 편익과 비용을 직관으로 평가해 결정
배외측 전두엽 피질: 미래 결과를 고려 → 사려 깊은 선택

1. 현재에 대한 편향(present bias): 미래 결과를 무시 · 과소평가

2. 극복 능력의 차이: 배외측 전두엽 피질이 덜 활발
→ 충동적 선택

→ 충동적인 사람은 범죄 · 사려 깊은 사람은 범죄 X

인적자본(human capital)에 대한 투자

공공정책: 범죄의 CE 또는 합법적 임금을 바꿈

교육 · 직업훈련 투자 → 인적자본 · 생산성 증가 → 합법적 임금 상승

① 모든 근로자의 임금 +20달러 (최저 1 → 21, 최고 100 → 120)

② 임금선이 위로 20달러 = 왼쪽으로 40명
104번째 근로자 52 → 72달러 (점 b → d)

③ CE = 52달러와 새 임금선이 점 e에서 만남
→ 범죄자 104 → 64명

→ 범죄의 임금 탄력성 −1.0 ~ −2.0
저숙련 임금 10% 증가 → 범죄 10~20% 감소

인적자본에 대한 투자: 고등학교 졸업

고교 중퇴자가 보호시설에 갈 가능성
= 대졸자의 13배

졸업 장려의 비용과 편익

비용:추가 1년 재학, 학생 1인당 6,000달러 (한 번)

편익:범죄 감소로 사회에 매년 약 1,600달러
범죄자 이력의 남은 기간(30~40년) 동안

→ 고등학교 교육 투자는
범죄를 줄이는 효율적인 방법

출처: Raphael and Stoll, Do Prisons Make Us Safer? (2008)

처벌의 확실성

경찰 · 법원 지출 증가 → 체포 · 처벌 확률 증가 → 범죄의 CE 감소

성공확률과 확실성 등가 (r₁ = 3/5 → 1/2)

성공확률과 범죄 (CE 52 → 35)

→ eu 156 → 105유틸 · CE 52 → 35달러 · 범죄자 104 → 70명 (합법적 근로자 130명)

실증: 교도소 수감 확률에 대한 범죄의 탄력성 −0.3 (수감 가능성 10% 증가 → 범죄율 3% 감소)

처벌의 가혹성(severity)

더 긴 징역형 → 처벌 증가 → 범죄의 CE 감소

① 처벌 25 → 35달러: 실패의 효용 −150 → −210유틸

② eu = 3/5 · 360 − 2/5 · 210 = 유틸 → CE 달러

③ 범죄자 104명(점 a) → 명(점 b)

투옥기간의 체감하는 보수(diminishing returns)

현재에 대한 편향:나중의 1년은 지금 결정에서 비중이 작음

노령범죄자:나이가 들수록 범죄 빈도 감소

더 비정해짐:긴 투옥 → 내적 처벌 약화 → CE 증가

교도소 내 학습:숙련된 범죄자 → 처벌 확률 감소

→ 처벌 강화의 범죄 감소 효과는 상대적으로 작음

감옥의 역할

미국 수감 인원: 수십 년간 7배 → 2008년 230만 명

미국 수감율은 OECD 국가 중위값의 7배

1. 저지(deterrence): 투옥의 위협 → 범죄의 CE 감소

2. 무력화(incapacitation): 범죄자를 격리
텍사스: 연간 비용 36,000 > 무력화 편익 15,000달러

3. 재활(rehabilitation): 석방 후 3년 안에 약 2/3 재체포
성인 프로그램은 효과 X · 비행 청소년은 보통의 감소

→ 수감 인원에 대한 범죄의 탄력성
대물범죄 −0.25 · 강력 범죄 −0.40

주: 교재 본문(p.539~540)에 수치가 있는 일곱 나라만 옮김
출처: OECD, Factbook 2010 (교재 그림 23−10)

범죄의 효율적 양

범죄 통제도 자원을 씀 → 효율적 범죄 수준은 0이 아님

범죄 1건당 피해자 비용: 절도 370 · 밤도둑 1,500 · 자동차 절도 4,000 · 무장강도 13,000달러

① 한계편익: 예방한 범죄 1건당 피해자 비용 1,500달러

② 한계비용: 쉬운 범죄부터 예방 → 우상향 (점 a → b)

③ 점 c: 한계편익 = 한계비용
→ 예방 건 · 겪는 범죄 건

→ 그 너머는 예방 비용 > 범죄를 감당하는 비용

직업선택과 한계저지: 균형 직업선택

범죄도 직업선택: 노동자 30명이 절도 · 강도 · 목수(합법) 중 선택

보수곡선은 우하향: 목수 = 노동수요곡선 · 범죄 = 수익이 큰 대상부터 범행 (범죄의 보수 = 범죄의 CE)

균형 조건: ① 내쉬균형(세 직업의 보수가 같음) ② 총합의 제약(30명 모두 고용) → 점 a · b · c: 10명씩, 보수 π*

→ 절도 처벌 강화: 절도 보수 π* → π′ → 이직 → 절도 4 · 강도 12 · 목수 14명, 보수 π** (< π*)

직업선택과 한계저지: 범죄대체

한계저지(marginal deterrence): 피해자 비용이 큰 범죄일수록 기대처벌이 커야 함

절도 처벌 강화의 결과: 6명이 직업을 바꿈 (강도로 2명 · 목수로 4명)

절도범 6명 감소:피해자 비용 −달러 (6 × 1,500)

강도범 2명 증가:피해자 비용 +달러 (2 × 13,000)

→ 범죄 피해자 비용 달러 증가: 범죄대체(crime substitution)

강도의 피해자 비용 ≈ 절도의 약 9배
→ 강도 1건이 늘 때 절도가 9건보다 적게 줄면 총 피해자 비용 증가
