# assets — 이 과목 전용 이미지

파일 이름 앞머리로 출처와 취급 방법을 구분한다 (데이터사이언스 과목과 같은 관례).

| 접두사 | 뜻 | 배포 |
|---|---|---|
| `cc-` | 외부에서 가져온 자유 라이선스 자료 | 가능. **슬라이드에 저작자·라이선스를 반드시 표기** |
| `tb-` | 교재에서 잘라 온 것 | **대외 배포 전 저작권 판단 대상** |
| (접두사 없음) | 직접 만든 것 | 자유 |

이 과목은 현재 `tb-` 셋뿐이고 `cc-` 는 없다.
개념도는 전부 인라인 SVG 로 다시 그렸다 (design.md §6.1) — 그래서 파일이 적다.

## 파일 목록

### tb-osullivan-cover.jpg
- 주교재 표지 — 오설리반의 도시경제학 제9판
- 출처: 박영사 (원서 McGraw Hill, *Urban Economics*, 9th ed.)
- 쓰는 곳: **1강 7쪽** 강의 교재
- 크기: 888×1200. 슬라이드에서 높이 300px 로 넣는다
- 받은 날: 2026-09-01 (교수 제공)

### tb-indiana-central-places.jpg
- 인디애나주 고용밀도를 높이로 세운 3차원 지도
- 출처: 오설리반, 『오설리반의 도시경제학』 제9판, 박영사, 2022, **그림 6−6 (p.124)**
- 쓰는 곳: **5강** 인디애나의 중심지역들 — 중심지이론의 도시위계를 실증으로 보이는 자리
- 크기: 1130×706. 슬라이드에서 높이 250px
- 3D 렌더링이라 SVG 재작도가 어려워 스캔을 그대로 쓴다

### tb-rent-surface.jpg
- 순환도로 도시의 토지 임대료 표면 (3차원)
- 출처: 오설리반, 『오설리반의 도시경제학』 제9판, 박영사, 2022, **그림 10−6 (p.206)**
- 쓰는 곳: **9강** 순환도로 도시에서의 토지 임대료 표면
- 크기: 1392×943. 슬라이드에서 높이 214px
- 같은 이유로 스캔을 그대로 쓴다

## 배포할 때

교재 판권면에 "무단전재와 복제를 금합니다" 가 적혀 있다.
`_scripts/build-site.sh` 로 배포본을 만들기 전에 `ls */assets/tb-*` 로 전수 확인하고
공개 여부를 판단한다 (CLAUDE.md 「저작권」 절).

세 파일 모두 강의 목적의 인용이며, 슬라이드마다 출처를 그림 아래에 적어 두었다
(design.md §4.5).
