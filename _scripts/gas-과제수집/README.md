# 과제수집 — 구글 폼 하나로 받아 주차·학생별 폴더로 가른다

구글 폼은 업로드된 파일을 **질문별 폴더 하나에 전부 쏟아붓는다.** 주차나 학생으로 가르는
기능이 없다. 이 스크립트가 제출이 들어올 때마다 파일을 옮긴다.

```
<루트>/02주차_클로드코드와위키/2020123456_홍길동/20260921-1432_my-wiki.zip
```

파일 이름 앞에 제출 시각이 붙는다. **재제출해도 덮어쓰지 않고 둘 다 남는다.**

---

## 폼은 한 학기에 하나뿐이다

학생은 **한 학기 내내 같은 주소**를 쓰고, 제출할 때 드롭다운에서 주차를 고른다.
**고른 값이 그대로 폴더 이름이 된다.** 그래서 매주 할 일이 없다.

| | |
|---|---|
| 처음 한 번 | 폼 만들기 · 파일 질문 추가 · 트리거 설치 |
| **매주** | **없음.** 같은 주소를 계속 쓴다 |
| 주차를 더할 때 | `설정.gs` 의 `주차목록` 에 한 줄 넣고 `주차항목갱신()` |

**폼을 복제하지 않는다.** 파일 업로드 질문이 있는 폼의 사본은 응답 폴더 연결이 끊어져
「파일 업로드 폴더 누락」이 뜨고 **폼이 응답 수집을 멈춘다**
([커뮤니티 스레드](https://support.google.com/docs/thread/305757159/missing-file-upload-folders-google-forms?hl=en)).
폼이 하나뿐이면 복제할 일 자체가 없다.

마감은 폼을 닫아 걸지 않는다. **제출 시각**이 폼 응답과 기록 시트에 남으므로 그것으로 가린다.

---

## 한 번만 하는 준비

### 1. 드라이브 폴더

`내 드라이브/과제제출/2026-2_데이터사이언스/` 를 만든다.

**`200_education` 안에 만들지 않는다.** 그 폴더는 Drive for desktop 이 로컬로 동기화한다
(`CLAUDE.md` §2 — 파일 수가 폭증하면 동기화가 망가진다). 과제 폴더는 수강생 × 주차 × 파일
수만큼 늘어난다. 만든 뒤 Drive for desktop 설정에서 `과제제출/` 을 동기화에서 뺀다.

폴더를 열었을 때 주소 끝의 긴 문자열이 **루트 폴더 ID** 다.

### 2. Apps Script 프로젝트

`script.google.com` 에서 새 프로젝트를 만들고 이 폴더의 세 파일을 그대로 붙여넣는다
(`설정.gs` · `Code.gs` · `설치.gs`). **폼에 붙이지 않는다** — 독립형 프로젝트 하나가
폼에 트리거를 건다.

`설정.gs` 의 `ROOT_FOLDER_ID` 를 채우고, `주차목록` 이 이번 학기와 맞는지 본다.

### 3. 폼 만들기

`폼만들기()` 를 실행한다. 처음이면 권한 승인 화면이 뜬다 (드라이브 · 폼 · 메일).

**「Google에서 확인하지 않은 앱입니다」가 뜬다.** 내가 만든 스크립트라 정상이다.
**고급 → (프로젝트 이름)(으)로 이동** 을 눌러 진행한다.

스크립트가 넣는 것:

| 질문 | 유형 | |
|---|---|---|
| `주차` | 드롭다운 · 필수 | 항목은 `설정.gs` 의 `주차목록`. **고른 값이 폴더 이름** |
| `학번` | 짧은 답변 · 필수 | 응답 검증 `^\d{10}$` — 자릿수는 `설정.gs` 의 `학번자릿수` |
| `이름` | 짧은 답변 · 필수 | |
| 하고 싶은 말 | 장문 · 선택 | 막힌 곳 · 질문 · 덧붙일 설명 |

설정도 함께 넣는다 — 이메일 주소 수집 켬 · 응답 수정 허용 끔.

**로그의 편집 주소를 열어 「파일 업로드」 질문을 추가한다.** 필수로 켜고
「하고 싶은 말」 위로 끌어 올린다. 파일 질문은 스크립트가 제목이 아니라 유형으로 찾으므로
제목은 아무거나 좋고 여러 개 두어도 된다.

**`주차` · `학번` · `이름` 제목은 스크립트가 이름으로 찾는다. 이 셋은 바꾸지 않는다.**

로그에 찍힌 폼 ID 를 `설정.gs` 의 `폼_ID` 에 넣는다.

### 4. 확인하고 설치한다

1. `설정확인()` — 루트 폴더 · 질문 · 파일 질문 · 트리거 · 드롭다운 항목을 한 번에 본다
2. `트리거설치()`
3. 본인 계정으로 **시험 제출**을 해 본다 (아래 「어떻게 확인하나」)
4. 로그에 찍힌 **학생에게 줄 주소**를 공지한다. 학기 내내 이 주소 하나다

## 주차를 더하거나 이름을 고칠 때

1. `설정.gs` 의 `주차목록` 을 고친다
2. `주차항목갱신()` 을 돌린다 — 폼의 드롭다운이 목록과 같아진다

이미 낸 제출에는 영향이 없다. **이름을 고치면 그 뒤 제출만 새 폴더로 간다** —
옛 폴더는 그대로 남으므로 필요하면 손으로 합친다.

## 마감 뒤에 하는 일

`점검()` 을 돌린다. 실행 로그에 이렇게 찍힌다.

```
응답 27건 · 제자리 아님 0개 · 사라짐 0개 · 못 읽음 0건
── 02주차_클로드코드와위키 ─ 26명
    2020123456_홍길동
    2020987654_김철수  (제출 2회)
 ?  202012_이영희                 ← 학번이 열 자리가 아니다. 오타 후보
```

**「제자리 아님」이 0 이 아니면** 트리거가 그 사이에 죽어 있었던 것이다.
`밀린것처리()` 를 돌린다. 이미 옮긴 것은 건드리지 않으므로 몇 번을 돌려도 안전하다.

## 함수

| 함수 | 언제 |
|---|---|
| `폼만들기()` | 학기에 한 번 |
| `주차항목갱신()` | `주차목록` 을 고친 뒤 |
| `설정확인()` | 설정을 고친 뒤. 제출이 없어도 돌아간다 |
| `트리거설치()` | 처음 한 번 |
| `트리거해제()` | 학기가 끝났을 때 |
| `점검()` | 주차 마감 뒤. 보기만 하고 고치지 않는다 |
| `밀린것처리()` | `점검()` 에서 「제자리 아님」이 나왔을 때 |
| `onSubmit(e)` | 손으로 돌리지 않는다. 트리거가 부른다 |

## 겪을 만한 것

**트리거는 조용히 죽는다.** 예외를 던져도 아무 화면에도 안 뜬다. 그래서 오류가 나면
메일로 알리고, 파일은 폼이 만든 기본 폴더에 **그대로 둔다.** 잃어버리는 경우는 없다.
`밀린것처리()` 가 뒤늦게 정리한다.

**학생이 주차를 잘못 고를 수 있다.** 이것이 이 방식의 유일한 새 위험이다.
`점검()` 이 주차별 제출자 명단을 찍으므로 빠진 사람과 이상한 자리가 눈에 띈다.
폴더를 옮기는 건 드래그 한 번이다. 목록에 **없는** 값이 들어오면 폴더를 만들지 않고
오류 메일을 보낸다 — 오타로 엉뚱한 폴더가 생기지는 않는다.

**응답자는 구글 로그인이 필요하다.** 파일 업로드 질문의 제약이다. 학교 계정이 아니어도
되지만, 개인 지메일로 폼을 만들면 **외부인도 낼 수 있다.** 학번 열 자리 검증으로 거른다.

**파일은 폼 주인의 드라이브에 쌓인다.** 용량이 빠듯해지면 폼의 파일 업로드 질문에서
개수·크기 상한을 걸거나, 학기 중에 로컬로 내려 비운다.

**기록 시트.** 루트 폴더에 `과제수집-기록` 이 자동으로 생긴다. 제출마다 성공·실패가
한 줄씩 쌓인다. 이것과 오류 메일, `점검()` 셋이 「받았는데 못 찾는」 사고를 막는 장치다.

## 어떻게 확인하나

| | 해 보는 것 | 이렇게 되어야 한다 |
|---|---|---|
| 1 | 2주차 · 학번 `2020000001` · 이름 `테스트` 로 파일 둘 제출 | `.../02주차_클로드코드와위키/2020000001_테스트/` 에 `20260914-HHmm_파일명` 둘 |
| 2 | 같은 학번으로 같은 주차에 다시 제출 | **폴더는 하나 그대로, 파일이 넷.** 시각이 달라 덮어쓰이지 않는다 |
| 3 | 같은 학번으로 **3주차**를 골라 제출 | `03주차_SGIS스킬/2020000001_테스트/` 가 새로 생긴다 |
| 4 | 학번을 `12345` 로 넣어 본다 | **폼이 제출을 막는다** (응답 검증) |
| 5 | `점검()` | 「제자리 아님 0개」, 주차별 명단이 찍힌다 |
| 6 | `트리거해제()` 후 제출 | 메일이 오고, 파일은 폼 기본 폴더에 남아 있다 |
| 7 | `트리거설치()` 후 `밀린것처리()` | 그 파일이 제자리로 옮겨진다 |

시험이 끝나면 시험 제출물을 지우고 휴지통까지 비운다.
