# assets — 이 과목 전용 이미지

파일 이름 앞머리로 출처와 취급 방법을 구분한다 (데이터사이언스·도시및지역경제학과 같은 관례).

| 접두사 | 뜻 | 배포 |
|---|---|---|
| `cc-` | 외부에서 가져온 자유 라이선스 자료 | 가능. **슬라이드에 저작자·라이선스를 반드시 표기** |
| `tb-` | 교재·신문·웹에서 잘라 온 것 | **대외 배포 전 저작권 판단 대상** |
| (접두사 없음) | 직접 만든 것 | 자유 |

이 과목은 `tb-` 40개뿐이고 `cc-` 는 없다. 12개 덱 가운데 가장 많다 —
원본 pptx 를 HTML 로 옮기면서 SVG 로 다시 그릴 수 없는 것만 잘라 왔기 때문이다
(사진 · 3D 렌더링 · 표 이미지 · 신문 그래픽 · 만화).

**출처가 확인된 것과 확인하지 못한 것을 아래에 나눠 적었다.** 확인하지 못한 것은
원본 pptx 에서 잘라 온 것으로 보이나 원 출처를 추적하지 못했다.
배포 판단 전에 이 목록부터 채운다.

## 배포할 때

교재 판권면에 "무단전재와 복제를 금합니다" 가 적혀 있고, 신문 그래픽과 사진에도
각각 권리자가 있다. `_scripts/build-site.sh` 로 배포본을 만들기 전에
`ls */assets/tb-*` 로 전수 확인하고 공개 여부를 판단한다 (CLAUDE.md 「저작권」 절).

2026-08-26 에 교수가 이 상태로 전체 공개를 결정했다. 위 2절의 출처를 채우면
그 판단의 근거가 분명해진다.
