# 7강 예시 — 광양 공간분석 로직

슬라이드에 넣은 수치가 어떻게 나왔는지 적는다. 코드가 아니라 **판단**을 적는다.

## 데이터

- COMPAS 「전기차 충전소 최적입지 선정」(광양시, `SBJ_2009_001`) 공개 데이터
- `08.광양시_격자별인구현황(100X100).geojson` — 100m 격자 47,032칸
- `01.광양시_충전기설치현황.csv` — 충전소 44곳 (lon·lat 포함)

## 판단한 자리와 이유

| 정한 것 | 어떻게 | 왜 |
|---|---|---|
| 격자 추리기 | `val` 이 있는 칸만 — 47,032 → **4,223칸** | `val` 이 없는 칸은 조사 대상이 아니다. 0 과 다르다 |
| 격자 중심 | 폴리곤 꼭짓점의 평균 | 100m 정사각이라 무게중심과 사실상 같다 |
| 좌표 → 미터 | 위도 34.97 기준 등거리 근사 | 시 하나 범위라 투영 왜곡이 무시할 만하다 |
| 공간가중 | 중심 사이 **150m 이내**를 이웃 | 격자가 100m 라 상하좌우(rook)가 잡히고 대각(141m)도 든다 |
| Moran's I 유의성 | **정규근사** (Cliff & Ord) | 무작위 순열은 난수를 쓴다. 이 과목은 난수를 쓰지 않는다 |
| Gi\* 임계 | \|z\| > 2.58 (99%) | 다중검정 보정은 하지 않았다 — **한계에 적었다** |
| DBSCAN eps | **700m** | 도보 10분 남짓. 충전소 이용권으로 잡았다 |
| DBSCAN minPts | **3** | 두 곳만으로 「군집」이라 부르기 어렵다 |

## 결과 (2026-09-09 실행)

- 격자 4,223칸 · 인구 합 145,683명 · 칸당 평균 34.5 · **중앙값 0**
- **Moran's I = 0.7294** (기대값 −0.00024 · z = 66.3) — 인구는 강하게 뭉쳐 있다
- LISA — HH 534칸(12.6%) · LL 3,019칸(71.5%) · HL 74 · LH 254 · 이웃없음 342
- Gi\* — 핫스팟 319칸 · **콜드스팟 0칸**. 가장 뜨거운 칸은 라라174597 (인구 1,115 · Gi\* 22.5)
- DBSCAN — 군집 6개 · 잡음 10곳(23%)

## 한계

- **콜드스팟이 0인 것은 자료의 성질이다.** 인구는 0 아래로 못 가고 빈 칸이 71%라
  평균이 낮게 눌린다. 「차가운 곳이 없다」가 아니라 「낮은 쪽으로는 더 낮아질 수 없다」는 뜻이다.
- Gi\* 에 다중검정 보정을 하지 않았다. 4,223번을 검정하므로 5%만 우연이어도 200칸이 나온다.
  **핫스팟 319칸을 그대로 믿지 않는다.**
- DBSCAN 군집 5는 섬진강휴게소다. 사는 곳이 아니라 **고속도로 휴게소**이며,
  같은 자리의 충전기 두 대가 각각 한 행으로 들어와 있다. 군집 6도 같은 사정이다.
- 이웃이 없는 342칸은 Moran's I 의 분모에 들어가지만 이웃 항이 비어 값을 끌어내린다.
