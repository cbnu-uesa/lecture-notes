# 시작하는 법

이 폴더를 통째로 복사해 자기 이름의 폴더로 만든다. 예: `~/my-wiki`

1. **자료를 넣는다** — 강의노트는 `raw/lectures/과목명/`, 논문은 `raw/papers/`,
   발표자료는 `raw/talks/`, 책 메모는 `raw/books/` 에 넣는다. PDF 여도 된다
2. **터미널에서 그 폴더로 가서 클로드를 연다**

   ```bash
   cd ~/my-wiki
   claude
   ```

3. **인제스트를 시킨다**

   ```
   raw/lectures/데이터사이언스/04-도시데이터소스.pdf 를 인제스트해 줘
   ```

4. **결과를 눈으로 본다.** `wiki/` 안의 페이지를 열어 **출처 없는 문장을 찾는다.**
   찾으면 지우라고 하거나 출처를 물어본다

규칙은 `CLAUDE.md` 에 있다. 마음에 안 드는 점이 생기면 그 파일을 고친다.
**이 위키는 내 것이고, 규칙도 내가 정한다.**

무엇을 왜 만드는지와 **어디까지 바꿔도 되는지**는 `계획.md` 에 있다.
2주차 실습에서 그 문서의 빈칸을 채운다.

## 폴더

```
raw/        모은 것 (강의노트·논문·발표자료·책 메모). 클로드가 고치지 않는다
notes/      내가 쓴 것 (필기·메모·아이디어). 클로드가 고치지 않는다
wiki/       클로드가 쓰는 것 (topics 개념·방법론 · sources 자료 한 건 + index·log)
questions/  강의가 말해 주지 않은 것을 클로드와 논의한 기록
templates/  페이지 서식 (개념 · 방법론 · 자료)
계획.md     한 학기 계획과 내가 정할 것. 빈칸을 채운다
```

## 이 위키를 공개하지 않는다

강의노트와 논문은 내 것이 아니다. 깃허브에 올릴 때 **반드시 비공개(private)** 로 만든다.
