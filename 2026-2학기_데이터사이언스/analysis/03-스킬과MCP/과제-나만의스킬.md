# 3주차 과제 — 나만의 스킬 만들기

**마감: 10월 2일**

수업에서는 남이 만든 MCP 를 붙여 썼다. 이번에는 **내가 반복하는 일**을 스킬로 만든다.

무엇을 만들지는 정해 주지 않는다. **자기 대화 기록에서 찾는다.**

---

## 왜 기록에서 찾나

스킬은 결국 **프롬프트에 매번 반복해 적던 것을 대신하는 것**이다.
그러니 먼저 내가 무엇을 반복했는지부터 알아야 한다.

머리로 고른 자동화 대상은 대개 빗나간다. "이런 게 있으면 편하겠다" 는 대부분
한 번 하고 마는 일이다. **실제로 세 번 넘게 한 일**은 기록에만 남아 있다.

## 마감이 두 주인 이유

**한 주는 반복을 쌓는 기간이다.** 3주차 수업 직후에 기록을 뒤지면 찾을 것이 적다.
그동안 클로드와 일을 계속하고, 그 기록에서 찾는다.

4주차에 연구질문을 정하면서 같은 일을 여러 번 시키게 된다. 거기서 나오는 경우가 많다.

---

## 1단계 — 반복을 찾는다

클로드에게 시킨다. 그대로 써도 된다.

> "**지난 2주 동안 클로드에서 작업한 모든 세션 기록을 검토했을 때**,
> 지금까지 나눈 대화와 커밋 기록에서
> 내가 **반복해서 같은 순서로 시킨 일**이 있으면 묶어서 목록으로 보여 줘.
>
> 각 항목마다 **몇 번 반복됐는지**, **스킬로 만들 값이 있는지**를 같이 판단해 주고,
> 가장 값이 큰 것부터 순서를 매겨 줘."

목록이 나오면 **눈으로 확인한다.** 클로드가 묶은 것이 실제로 같은 일인지,
반복 횟수가 맞는지 본다. 틀렸으면 되묻는다.

**찾은 목록을 그대로 저장해 둔다.** 제출물에 들어간다.

## 2단계 — 하나를 고른다

여러 개가 나와도 **하나만 만든다.**

고르는 기준은 셋이다.

1. **세 번 넘게 한 일인가** — 규격화에도 품이 든다. 두 번이면 그냥 시키는 게 빠르다
2. **절차인가** — "어떤 순서로 한다" 여야 한다.
   "면적 하한은 60㎡" 같은 **사실과 규범은 CLAUDE.md 자리**다
3. **매번 같은 결과가 나와야 하는 일인가** — 그때그때 다르게 해야 하는 일은 스킬이 아니다

**고른 이유를 한 문단으로 적는다.** 무엇이 몇 번 반복됐는지가 들어가야 한다.

## 3단계 — skill-creator 로 만든다

빈 파일에서 쓰지 않는다. 앤트로픽이 공개한 `skill-creator` 를 쓴다.

```
/plugin        →  skill-creator
```

설치했으면 부르지 않아도 꺼내진다. 그냥 시키면 된다.

> "**〈고른 일〉 스킬을 만들어 줘.**
> 〈무엇을 어떤 순서로 하는 일인지 설명〉
>
> **부르지 않아도 꺼내지게** description 을 쓰고,
> 만든 뒤에 **시험 프롬프트 두세 개로 실제로 돌려서** 보여 줘."

skill-creator 가 이 순서로 간다.

1. 무엇을 하는 스킬인지 되묻기 — 언제 꺼내고 결과가 어떤 꼴인지
2. `SKILL.md` 초안 쓰기
3. 시험 프롬프트 두세 개 돌리기
4. 쓴 결과와 쓰지 않은 결과를 대조
5. 고쳐 쓰고 다시 돌리기
6. `description` 다듬기

## 4단계 — 부르지 않고 꺼내지는지 확인한다

`/이름` 으로 부르면 당연히 된다. **그건 확인이 아니다.**

스킬이 할 일을 **자연어로만 말해 본다.** 클로드가 스스로 그 스킬을 꺼내야 한다.
안 꺼내면 `description` 이 부족한 것이다.

클로드는 스킬을 **안 꺼내는 쪽으로 잘 틀린다.** 그래서 description 은
"무엇을 한다" 로 끝내지 않고 **"어떤 말이 나오면 이것을 쓰라"** 까지 적는다.

```
description: 월별 요약을 만든다.               ← 언제 쓰는지를 말하지 않는다
description: 월별 요약을 만든다. "이번 달 정리해 줘",
  "월 보고" 같은 말이 나오면 이것을 쓴다.       ← 이렇게
```

**꺼내진 화면을 남긴다.** 제출물에 들어간다.

## 막히면

**어디까지 갔고 무엇에 막혔는지 적어서 낸다.** 그것도 결과다.
반복을 못 찾은 것도 결과다 — 그 경우 무엇을 찾아봤는지 적는다.

---

## 제출물

| 무엇 | 어느 정도면 되나 |
|---|---|
| **스킬 폴더 전체** | `SKILL.md` 와 그 아래 파일을 통째로 |
| 고른 이유 한 문단 | **무엇이 몇 번 반복됐는지**가 들어갈 것.<br>텍스트로 써도 되고 md 파일로 내도 된다 |
| 반복 목록 | 1단계에서 클로드가 찾아 준 것 |
| 꺼내진 화면 | **부르지 않았는데** 스스로 꺼내진 화면 |

폴더를 통째로 압축해 낸다.

## 보는 것 셋 — 분량은 세지 않는다

1. **반복의 근거가 있는가** — "이럴 것 같아서" 가 아니라 기록에서 찾았는가
2. **사실이 아니라 절차인가** — 사실과 규범이면 CLAUDE.md 자리다
3. **스스로 꺼내지는가** — `description` 이 「언제 쓰는지」를 말하는가
