# 3주차 과제 — SGIS 스킬 만들기

**마감: 5주차 수업 시작 전**

수업에서 만든 인제스트 스킬은 내 위키를 다뤘다. 이번에는 **바깥 데이터**를 다루는 스킬을
만든다. 5주차 「도시 데이터는 어디에 있는가」 실습에서 **자기가 만든 이 스킬로 데이터를 받는다.**

---

## 무엇을 감싸나

SGIS(통계지리정보서비스, 국가데이터처)는 오픈API 93종을 연다. 인구·가구·주택·사업체
통계, 행정구역 경계, 지오코딩, 격자, 자연재해까지 도시를 다루는 자료가 모여 있다.

그런데 쓰기가 번거롭다. 두 가지 때문이다.

- **API 마다 요청변수가 다르다.** 무엇을 넣어야 하는지 매번 문서를 뒤져야 한다
- **토큰이 4시간짜리다.** 인증키로 토큰을 받고, 만료되면 다시 받아야 한다

이 번거로움을 **한 번만 적어 두고 다시 안 하는 것**이 스킬이다.

## 마감이 5주차인 이유

3주차에 내지만 두 주를 준다. 이유가 둘이다.

- **인증키 발급에 시간이 걸릴 수 있다.** 오늘 신청한다
- **4주차에 연구질문을 정한다.** 그때라야 어느 API 가 필요한지 알 수 있다

---

## 1단계 — 인증키를 오늘 신청한다

1. **sgis.mods.go.kr** 회원가입 후 로그인
2. 개발지원센터 → 인증키 신청 (약관동의 → 정보입력 → 신청)
3. **사용기간을 학기가 끝날 때까지 덮게 잡는다.** 15일로 잡으면 5주차에 만료돼 있다
4. 받은 **서비스 ID** 와 **보안 Key** 를 잘 둔다

**키는 각자 받는다.** 약관이 키를 남과 공유하는 것을 금지한다. 하루 50,000회까지 쓸 수 있다.

> 3주차에 붙인 KOSIS MCP 는 인증키가 없었다. 대부분의 공공 API 는 이렇게 키가 필요하다.
> **그 차이를 겪는 것도 과제의 내용이다.**

## 2단계 — 감쌀 API 를 두세 개 고른다

93개를 다 하지 않는다. **두세 개면 된다.**

문서: `sgis.mods.go.kr` → 개발지원센터 → API 정의 및 사용예제

4주차에 정한 자기 연구질문에 필요한 것으로 고른다. 아직 문제가 안 정해졌으면
관심 있는 지역·주제로 임시로 고르고, 4주차가 지난 뒤에 바꾼다.

**고른 이유를 한 줄로 적어 둔다.** 제출물에 들어간다.

## 3단계 — 스킬을 쓴다

**코드는 클로드가 쓴다.** 학생이 하는 일은 무엇을 감쌀지 고르고, 되는지 확인하고,
안 되면 되묻는 것이다. 파이썬을 몰라도 된다.

```
~/.claude/skills/<이름>/
├── SKILL.md      언제 쓰는 스킬인지 + 절차
└── (스크립트)     호출하는 코드
```

`description` 이 **「언제 쓰는 스킬인지」**를 말해야 한다. 그래야 부르지 않아도 클로드가
스스로 꺼낸다 — 수업에서 인제스트 스킬로 확인한 그 기준이다.

프롬프트 예시다. 그대로 써도 되고 자기 말로 바꿔도 된다.

> "SGIS 오픈API 중 **〈고른 API〉** 를 쓰는 스킬을 만들려고 해.
> 문서는 `sgis.mods.go.kr` 에 있어. **먼저 무엇을 만들지 말하고** 내가 좋다고 하면 써 줘.
>
> 조건이 셋이야.
> ① 인증키는 **환경변수**로 받아. 어느 파일에도 적지 마.
> ② 토큰이 4시간짜리니까 **만료되면 알아서 다시 받게** 해.
> ③ 받은 데이터에 **어느 API 에서 왔는지** 함께 남겨."

## 4단계 — 실제로 받고 확인한다

숫자가 나왔다고 끝이 아니다. **셋을 확인한다.**

1. **자릿수가 그럴듯한가** — 청주시 인구가 8만이나 800만으로 나오면 무언가 틀렸다
2. **어느 API 에서 왔는지 적혔는가**
3. **토큰이 만료된 뒤에도 되는가** — 4시간 뒤에 한 번 더 돌려 본다.
   사람이 다시 받아야 한다면 아직 안 된 것이다

## 막히면

**어디까지 갔고 무엇에 막혔는지 적어서 낸다.** 그것도 결과다.
키 발급이 늦어지는 것, API 가 오류를 뱉는 것, 응답이 비는 것 — 다 겪는 일이다.
혼자 두 시간 붙들지 않는다.

---

## 제출물

| 무엇 | 어느 정도면 되나 |
|---|---|
| `SKILL.md` | **부르지 않아도 꺼내진 화면**을 함께 |
| 스크립트 | 토큰 갱신을 사람이 안 해도 되게 |
| 받은 데이터 한 조각 | **어느 API 에서 왔는지** 적혀 있을 것 |
| 고른 이유 · 막힌 기록 | 각각 몇 줄 |

폴더를 통째로 압축해 낸다. **인증키가 안 들어갔는지 압축 전에 확인한다.**

## 보는 것 넷 — 분량은 세지 않는다

1. **스스로 꺼내지는가** — `description` 이 「언제 쓰는지」를 말하는가.
   "SGIS API 를 호출한다" 는 언제 쓰는지를 말하지 않는다
2. **인증키가 어느 파일에도 없는가** — 6주차에 이 폴더를 깃허브에 올린다.
   여기서 새면 **키가 공개된다.** 지우고 다시 올려도 이력에 남는다
3. **출처가 붙어 있는가** — API 이름·기관·조회 날짜
4. **토큰 4시간을 사람이 안 만지는가**

## 5주차에 이것으로 한다

자기 연구질문의 데이터를 이 스킬로 받는다. 수업에서 셋을 나란히 놓고 본다 —
**손으로 내려받기 · API 직접 호출 · 내가 만든 스킬.**
