# analysis — 실습 자료

**주차 폴더 하나가 그 주 실습에 쓰는 것 전부다.** 학생에게 나눠 줄 때도 폴더째 준다.

```
02-클로드코드와위키/  student-wiki/ — 지식 위키 씨앗 (규칙 · 계획서 · 페이지 서식)
07-기술적분석/        세종 아파트 실거래가
09-진단적분석1/       아산 의료 접근성
10-진단적분석2/       세종 회귀
11-예측적분석/        화성 인구 — 11강과 12강이 함께 쓴다
13-처방적분석/        광양 충전소 최적입지
data/                 원자료. 모든 주차가 공유한다 (깃에 없다)
```

## 분석 주차 (7·9·10·11·12·13강)

슬라이드에 나오는 모든 숫자는 여기서 나온다. 스크립트를 돌리면 같은 값이 다시 나오고,
결과 표는 CSV 로 남는다. **자기 폴더 안에서 돌린다.**

```bash
cd 07-기술적분석 && python3 07-세종주택시장.py
cd 09-진단적분석1 && python3 09-아산의료접근성.py
cd 10-진단적분석2 && python3 10-세종회귀.py
cd 11-예측적분석 && python3 11-화성인구.py
cd 13-처방적분석 && python3 13-광양충전소.py
```

외부 라이브러리를 쓰지 않는다. 표준 라이브러리만으로 회귀까지 직접 푼다.

주차 폴더마다 파일이 셋이다.

| 무엇 | 예 |
|---|---|
| 분석 스크립트 | `07-세종주택시장.py` |
| 판단 근거와 함정 | `07-세종주택시장-로직.md` — **코드보다 이쪽을 먼저 읽는다** |
| 결과 표 | `07-세종주택시장-동별.csv` 등. 스크립트가 다시 만든다 |

## 2주차 — student-wiki

학생이 자기 지식 위키를 만드는 씨앗이다. 폴더를 복사해 `~/my-wiki` 로 쓴다.
`계획.md` 를 먼저 읽고 빈칸을 채우게 한다. 규칙은 `CLAUDE.md` 에 있고,
**그 규칙을 학생이 고치는 것이 실습의 핵심**이다.

(세종 실거래가를 7강과 10강이 함께 읽는다). 스크립트는 `analysis/data/` 를 먼저 보고,

전부 공개 데이터이고 2026-08-25 에 로그인 계정으로 "전체 내려받기" 해서 받았다.
비공개 표시 데이터는 쓰지 않는다.

**`data/` 는 깃에 올리지 않는다** (`.gitignore`). 드라이브에는 두되 공개 저장소로는
내보내지 않는다는 뜻이다. 학생은 compas.lh.or.kr 에 가입해 과제별 전체 내려받기로
직접 받는다 — 원자료를 강의 사이트에 올리지 않는 것이 이 과목의 방침이다
(`강의계획.md` §4).
