# analysis — 슬라이드 수치를 만드는 코드와 자료

7·9·10·11·12강 슬라이드에 나오는 모든 숫자는 여기서 나온다.
스크립트를 돌리면 같은 값이 다시 나오고, 결과 표는 CSV 로 남는다.

```bash
python3 07-세종주택시장.py      # 7강 기술적 분석
python3 09-아산의료접근성.py    # 9강 진단적 분석 Ⅰ
python3 10-세종회귀.py          # 10강 진단적 분석 Ⅱ
python3 11-화성인구.py          # 11·12강 예측적 분석
python3 13-광양충전소.py        # 13강 처방적 분석
```

외부 라이브러리를 쓰지 않는다. 표준 라이브러리만으로 회귀까지 직접 푼다.

## 파일 구성

| 무엇 | 예 |
|---|---|
| 분석 스크립트 | `07-세종주택시장.py` |
| 판단 근거와 함정 | `07-세종주택시장-로직.md` — **코드보다 이쪽을 먼저 읽는다** |
| 결과 표 | `07-세종주택시장-동별.csv` 등. 스크립트가 다시 만든다 |
| 원자료 | `data/` — 아래 참조 |

## data/ — 원자료

스크립트가 읽는 COMPAS 공개 데이터 원본이다. 코드가 그 자리에서 바로 돌도록 함께 둔다.
없으면 스크립트가 `~/data/compas/<과제slug>/` 를 대신 본다.

| 파일 | 과제 | subjNo |
|---|---|---|
| `3.세종시_아파트(매매)_실거래가.csv` | 주택 시장 특성분석 (세종, 2021) | SBJ_2102_001 |
| `2.아산시_주민등록인구현황.csv` | 의료 취약지역 도출 (아산, 2024) | SBJ_2405_001 |
| `21.아산시_병원정보.csv` | 〃 | 〃 |
| `23.아산시_약국현황.csv` | 〃 | 〃 |
| `1.화성시_인구데이터.xlsx` | 인구예측모델 비교 (화성, 2023) | SBJ_2307_001 |
| `01.광양시_충전기설치현황.csv` | 전기차 충전소 최적입지 (광양, 2020) | SBJ_2009_001 |
| `02.광양시_주차장_공간정보.csv` | 〃 | 〃 |
| `08.광양시_격자별인구현황(100X100).geojson` (16MB) | 〃 | 〃 |

여덟 개 19MB이며, 격자 geojson 하나가 그중 16MB다.
전부 공개 데이터이고 2026-08-25 에 로그인 계정으로 "전체 내려받기" 해서 받았다.
비공개 표시 데이터는 쓰지 않는다.

**`data/` 는 깃에 올리지 않는다** (`.gitignore`). 드라이브에는 두되 공개 저장소로는
내보내지 않는다는 뜻이다. 학생은 compas.lh.or.kr 에 가입해 과제별 전체 내려받기로
직접 받는다 — 원자료를 강의 사이트에 올리지 않는 것이 이 과목의 방침이다
(`강의계획.md` §4).
