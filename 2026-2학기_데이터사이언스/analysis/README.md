```

07-기술적분석/        세종 아파트 실거래가
08-접근성분석/        아산 2SFCA (실습 표준노드링크 · 과제 OSM)
09-회귀분석/          세종 회귀 · 가정 진단 · 로지스틱 (2026-11-09 새 9강)
10-머신러닝/          세종 의사결정나무 · 랜덤포레스트 · SHAP (2026-11-09 새 10강)
09-진단적분석1/       옛 9강 (보관/09-진단적분석1.html) — 아산 의료 접근성

13-처방적분석/        광양 충전소 최적입지
data/                 원자료. 모든 주차가 공유한다 (깃에 없다)
```

## 분석 주차 (7·8·9·10·11·12·13강)

슬라이드에 나오는 모든 숫자는 여기서 나온다. 스크립트를 돌리면 같은 값이 다시 나오고,
결과 표는 CSV 로 남는다. **자기 폴더 안에서 돌린다.**

```bash
cd 07-기술적분석 && python3 07-세종주택시장.py   # 07-세종군집.py · 07-세종단지군집.py 도 같은 폴더
cd 08-접근성분석 && ~/.venvs/osmnx/bin/python 08-아산2SFCA.py   # 8강만 osmnx 가 필요하다
cd 09-회귀분석 && ~/.venvs/osmnx/bin/python 09-세종회귀진단.py         # statsmodels 가 필요하다
cd 10-머신러닝 && ~/.venvs/osmnx/bin/python 10-세종랜덤포레스트.py     # scikit-learn · shap 이 필요하다
cd 11-예측적분석 && python3 11-화성인구.py
cd 13-처방적분석 && python3 13-광양충전소.py
```

외부 라이브러리를 쓰지 않는다. 표준 라이브러리만으로 회귀까지 직접 푼다.
예외는 8·9·10강이다. 이 셋은 Drive 밖 가상환경 `~/.venvs/osmnx` (osmnx · statsmodels · scikit-learn · shap)에서 돌린다.
예외는 8강이다. 학생이 클로드에게 시키는 방식과 같은 도구로 값을 내려고 geopandas · networkx · osmnx 를 쓴다 (`pip install osmnx scikit-learn matplotlib`).

주차 폴더마다 파일이 셋이다.

| 무엇 | 예 |
|---|---|
| 분석 스크립트 | `07-세종주택시장.py` |
| 판단 근거와 함정 | `07-세종주택시장-로직.md` — **코드보다 이쪽을 먼저 읽는다** |
| 결과 표 | `07-세종주택시장-동별.csv` 등. 스크립트가 다시 만든다 |
