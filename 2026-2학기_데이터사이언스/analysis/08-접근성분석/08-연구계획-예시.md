# 연구계획: 아산 거주자의 차량 10분 의사 접근성 (2SFCA)

## 1. 연구질문과 조건

연구질문은 「아산의 거주자는 차로 10분 안에서 의사를 얼마나 만날 수 있고, 어느 곳이 낮은가」이다.

- 측정 방법: 2단계 유동 집수역법(2SFCA, two-step floating catchment area)
- 수요: 2023년 100m 격자 인구
- 공급: 의원, 병원, 종합병원, 보건소, 보건지소, 보건진료소의 의사 수(`doc_cnt`)
- 거리: 표준링크의 제한속도(`MAX_SPD`)로 계산한 최단 통행시간
- 임계시간: 10분

2SFCA 는 두 번 나눈다. 1단계에서 기관 j 마다 10분 안 격자 인구 합으로 의사 수를 나눠 공급비 R_j 를 구한다. 2단계에서 격자 i 마다 10분 안 기관의 R_j 를 더해 접근성 A_i 를 구한다. A_i 의 단위는 "인구 1명당 의사 수"이며, 보고할 때는 1만 명당으로 바꾼다.

이 계획은 분석 전 단계다. 아래 "정해야 할 것"을 확인받기 전에는 분석을 시작하지 않는다.

## 2. 자료 점검 결과

원자료 폴더에 `원자료/` 하위 폴더가 없어 다섯 파일이 있는 폴더 자체를 `원자료/` 로 본다. 아래 값은 파일을 열어 직접 센 것이다. 해석이 들어간 부분은 "추측"으로 표시했다.

### 2.1 격자 인구 `아산시_거주인구_격자_2021-2023.csv`

- 행 수: 165,102행. 2021·2022·2023년이 55,034행씩이다
- 열(20개): `gid`(격자 번호, 문자), `year`, 성별·연령대 18개 열 `m_20g_pop`, `w_20g_pop`, … `m_100g_pop`, `w_100g_pop`
- 연령: 20대부터 100세 이상까지다. 20세 미만 열은 없다
- 인코딩: UTF-8(BOM)
- 좌표: 없다. `gid` 로 격자 경계와 붙인다
- 2023년 빈칸: 55,034개 격자 가운데 18개 열이 모두 빈칸인 격자가 45,096개다. 값이 0인 격자가 8,668개, 0보다 큰 격자가 1,270개다
- 2023년 인구 합: 182,558명. 격자 하나의 최대값은 1,669명이다
- 0보다 큰 값의 최소는 6이다. 1~5 값은 하나도 없다. 작은 값을 0 또는 빈칸으로 가린 것으로 추측한다(확인하지 않았다)
- README 에 따르면 격자 인구 합은 주민등록인구의 52.8%다

### 2.2 격자 경계 `아산시_격자.geojson`

- 행 수: 55,034개 폴리곤. 열은 `gid` 하나와 geometry 다
- 좌표계: EPSG:4326(경위도)
- 면적: EPSG:5179 로 바꿔 재면 모두 10,000㎡(100m × 100m)다
- 빈칸: 없다
- `gid` 는 모두 "다바"로 시작하는 8자리이고, 인구 파일 2023년 `gid` 55,034개와 하나도 빠짐없이 맞는다

### 2.3 병원정보 `아산시_병원정보.csv`

## 3. 정해야 할 것 (선택지와 추천)

분석 중에 판단이 갈리는 자리다. 추천은 내 의견이며, 확인받은 뒤에 쓴다.

### D1. 수요 인구에 무엇을 넣는가

- 가. 2023년 18개 열의 합(20세 이상 전체)
- 나. 연령 가중(예: 고령층 가중)
- 추천: 가. 연구질문이 "거주자"이고 조건에 가중이 없다. 20세 미만이 빠진다는 점은 한계로 적는다

### D2. 인구 빈칸을 어떻게 다루는가

- 가. 빈칸을 0으로 본다
- 나. 빈칸 격자를 분석에서 뺀다
- 추천: 가. 수요 합은 두 방법이 같다. 다만 결과 지도에서는 인구가 0인 격자를 색칠하지 않는다. 사람이 없는 곳의 접근성 값은 읽을 대상이 아니다

### D3. 공급 기관의 범위

- 가. 조건의 여섯 종별 191곳을 모두 넣는다(의사 0명 20곳은 공급 0으로 계산에 영향이 없다)
- 나. 의사 0명 기관을 미리 뺀다
- 추천: 가. 결과는 같고, 보건진료소가 있다는 사실을 지도에 남길 수 있다. 치과·한방·요양·정신병원을 뺀 이유는 계획에 적는다

### D4. 도로망을 만드는 법

- 가. 표준링크를 방향 그래프로 만든다. 각 링크는 `F_NODE`→`T_NODE` 한 방향이다
- 나. 무방향 그래프로 만든다(일방통행을 무시)
- 추천: 가. 표준링크는 양방향 도로를 두 링크로 나눠 적으므로(5,652쌍) 방향 그래프가 원래 뜻에 맞다. 390개 한 방향 링크가 일방통행인지 누락인지는 지도로 확인한다
- 기관에서 격자로 가는 시간과 격자에서 기관으로 가는 시간이 다를 수 있다. 추천은 "격자 → 기관"(거주자가 병원에 가는 방향) 하나로 통일하는 것이다

### D5. 링크 통행시간

- 통행시간(분) = 링크 길이(m) ÷ (`MAX_SPD` × 1000 / 60)
- 길이: 링크 geometry 를 EPSG:5179 로 바꿔 잰다. 경위도 그대로 재면 단위가 도(°)라 틀린다
- 10km/h 링크(536개): 가. 그대로 쓴다 / 나. 30km/h 등으로 바꾼다. 추천은 가. 바꿀 근거가 자료에 없다. 다만 위치를 지도로 보고 단지 내 도로·진입로인지 확인한다
- 길이 1m 미만 9개는 그대로 둔다(통행시간이 0에 가까워 결과에 영향이 거의 없다). 중복 쌍 8개는 짧은 쪽 하나만 남긴다
- 교차로 지체·신호는 넣지 않는다. 제한속도로 달린다고 가정하므로 실제보다 시간이 짧게 나온다. 이 점은 한계로 적는다

### D6. `ROAD_USE`·`REST_VEH` 링크

- 가. 그대로 둔다
- 나. 통행 제한으로 보고 뺀다
- 추천: 가. 뜻을 확인하지 못했으므로 빼는 근거가 없다. 지도로 위치를 보고, 뜻이 확인되면 다시 정한다

### D7. 끝 노드가 없는 링크 103개

- 가. 링크 geometry 끝점으로 임시 노드를 만들어 그래프에 넣는다
- 나. 뺀다
- 추천: 나. 시 경계 밖으로 나가는 도로라 아산 안 이동에는 거의 쓰이지 않는다. 빼기 전후 가장 큰 연결 요소의 노드 수를 비교해 영향을 확인한다

### D8. 연결되지 않은 도로 조각

- 가. 가장 큰 강하게 연결된 요소(strongly connected component)만 쓴다
- 나. 전체를 쓰고 도달하지 못하는 쌍은 무한대로 둔다
- 추천: 가. 작은 조각에 붙은 격자는 어디에도 못 가는 것으로 나와 접근성이 0이 되는데, 이는 자료 결함이다. 빠지는 노드 수와 위치를 표와 지도로 남긴다

### D9. 격자를 도로에 붙이는 법

- 가. 격자 중심점에서 가장 가까운 노드(직선거리)
- 나. 가장 가까운 링크 위의 점(링크를 쪼개 새 노드를 만든다)
- 다. 가. 에 더해 중심점에서 노드까지 거리를 걷거나 느리게 가는 시간으로 더한다
- 추천: 가. 를 기본으로 하고, 중심점-노드 거리를 함께 저장한다. 노드가 2,311개라 노드 사이 간격이 넓은 곳이 있다. 붙인 거리가 큰 격자(예: 1km 넘음)를 지도로 보고, 많으면 다. 로 바꾼다
- 인구가 0보다 큰 격자만 붙인다(1,270개). 인구 0 격자는 수요에도 결과 해석에도 쓰지 않는다

### D10. 기관을 도로에 붙이는 법

- 가. 기관 좌표에서 가장 가까운 노드
- 나. 가장 가까운 링크 위의 점
- 추천: 가. 격자와 같은 방법을 써야 둘 사이 시간이 공정하다. 붙인 거리도 함께 저장한다
- 같은 좌표의 기관(47곳)은 같은 노드에 붙는다. 기관별로 R_j 를 따로 구해도 되고, 노드별로 의사 수를 합쳐도 결과는 같다. 추천은 기관별 유지(표에서 기관 이름으로 확인하기 쉽다)

### D11. 임계시간 안 판정과 거리 감쇠

- 가. 10분 이하는 1, 넘으면 0(원래 2SFCA)
- 나. 10분 안에서 시간에 따라 가중(E2SFCA 등)
- 추천: 가. 조건이 "10분 안"이다. 10분 이하에 같은 노드(0분)도 포함한다

### D12. 시 경계 효과

- 공급은 아산 안 기관뿐이고 도로도 시 경계에서 끊긴다. 천안 등 이웃 시의 의사를 이용하는 경계 지역(특히 천안과 맞닿은 동쪽)은 값이 낮게 나온다
- 가. 그대로 계산하고, 경계에서 10분 거리 안 격자를 지도에 표시해 해석을 따로 한다
- 나. 이웃 시 자료를 더한다(이 자료에 없다)
- 추천: 가. 결과 보고에서 경계 근처의 낮은 값을 "의료 부족"으로 단정하지 않는다

## 4. 분석 단계

각 단계는 앞 단계의 확인이 끝나야 다음으로 넘어간다. 좌표 계산은 모두 EPSG:5179(미터)로 한다.

### 1단계. 수요 격자 만들기

- 입력: 격자 인구 CSV(2023년), 격자 geojson
- 처리: 2023년 행만 고른다 → 18개 열을 합해 `pop` 을 만든다(D1·D2) → `gid` 로 경계에 붙인다 → EPSG:5179 로 바꾸고 중심점을 구한다
- 산출물: `산출/수요격자.gpkg` (`gid`, `pop`, 중심점)
- 검토할 지도: 격자 인구 지도(0인 격자는 회색)
- 검토할 표: 인구 구간별 격자 수
- 확인할 값: 2023년 행 55,034 / 인구 합 182,558 / 인구 0보다 큰 격자 1,270 / 붙지 않은 `gid` 0

### 2단계. 공급 기관 만들기

- 입력: 병원정보 CSV
- 처리: 여섯 종별만 고른다(D3) → 경위도로 점을 만든다(EPSG:4326) → EPSG:5179 로 바꾼다
- 산출물: `산출/공급기관.gpkg` (`mdcl_inst`, `mdcl_gbn`, `doc_cnt`, 점)
- 검토할 지도: 종별 색, 의사 수 크기로 그린 기관 지도. 격자 인구 위에 겹친다
- 검토할 표: 종별 기관 수·의사 수(2.3절 표와 같아야 한다)
- 확인할 값: 191곳 / 의사 369명 / 의사 0명 20곳 / 시 경계 밖 점 0

### 3단계. 도로망 그래프 만들기

- 입력: 표준노드, 표준링크
- 처리: EPSG:5179 로 바꿔 링크 길이를 잰다 → 통행시간을 계산한다(D5) → 끝 노드 없는 링크를 정리한다(D7) → 방향 그래프를 만든다(D4) → 가장 큰 강하게 연결된 요소를 남긴다(D8)
- 산출물: `산출/도로그래프.graphml`, `산출/링크_통행시간.gpkg`
- 검토할 지도: `MAX_SPD` 별 색으로 그린 링크 지도 / 한 방향 링크 390개 위치 / 10km/h 링크 위치 / 빠진 조각 위치
- 검토할 표: 처리 전후 노드 수·링크 수·총연장 / `MAX_SPD` 별 링크 수
- 확인할 값: 링크 6,050 → 정리 뒤 개수 / 큰 요소에 남은 노드 비율 / 링크 통행시간 최대값(5.3km 링크가 몇 분인지) / 통행시간 음수·무한대 0개

### 4단계. 격자와 기관을 도로에 붙이기

- 입력: 1~3단계 산출물
- 처리: 인구가 있는 격자 중심점과 기관 점을 가장 가까운 노드에 붙인다(D9·D10). 붙인 거리를 열로 남긴다
- 산출물: `산출/격자_노드.csv`, `산출/기관_노드.csv`
- 검토할 지도: 붙인 거리 지도(격자·기관을 선으로 노드와 이어 그린다)
- 검토할 표: 붙인 거리 분포(중앙값, 90분위, 최대) / 붙인 거리 1km 넘는 격자·기관 목록
- 확인할 값: 붙인 격자 1,270 / 붙인 기관 191 / 노드 하나에 붙은 격자·기관 최대 수

### 5단계. 통행시간 행렬

- 입력: 도로 그래프, 격자·기관 노드
- 처리: 각 격자 노드에서 출발해 10분까지만 다익스트라(Dijkstra) 최단경로를 구한다(D4: 격자 → 기관 방향). 10분 안 기관만 남긴다
- 산출물: `산출/OD_10분.csv` (`gid`, `mdcl_inst`, 분)
- 검토할 지도: 예시 격자 2~3곳(도심 한 곳, 읍면 한 곳)의 10분 도달 범위
- 검토할 표: 격자마다 10분 안 기관 수 분포
- 확인할 값: 10분 안 기관이 0인 격자 수와 인구 / 같은 노드 쌍 시간 0 / 임의 두 쌍을 손으로 따져 본 시간과 비교

### 6단계. 2SFCA 1단계: 기관별 공급비

- 입력: OD 표, 수요 격자, 공급 기관
- 처리: 기관 j 마다 10분 안 격자 인구 합 P_j 를 구하고 R_j = `doc_cnt` / P_j 를 계산한다
- 산출물: `산출/기관_공급비.csv` (`mdcl_inst`, `doc_cnt`, P_j, R_j)
- 검토할 표: R_j 상위·하위 10곳 / P_j 가 0인 기관(10분 안에 인구가 없다)
- 확인할 값: P_j = 0 인 기관 수와 의사 수(이 의사는 계산에서 사라진다)

### 7단계. 2SFCA 2단계: 격자별 접근성

- 입력: OD 표, 기관 공급비
- 처리: 격자 i 마다 10분 안 기관의 R_j 를 더해 A_i 를 구한다 → 1만 명당 의사 수로 바꾼다
- 산출물: `산출/격자_접근성.gpkg` (`gid`, `pop`, A_i, 1만 명당)
- 검토할 지도: 격자 접근성 지도(분위 구간), 시 경계 10분 안 띠 표시(D12)
- 검토할 표: 읍면동별 인구 가중 평균 접근성, 접근성 0 격자의 인구 합
- 확인할 값: 인구 가중 A_i 의 합 Σ(pop_i × A_i) 가 P_j > 0 인 기관의 의사 수 합과 같다(2SFCA 의 보존 성질). 6단계에서 사라진 의사를 빼면 369명과 맞아야 한다

### 8단계. 낮은 곳 찾기

- 입력: 격자 접근성
- 처리: 접근성 하위 구간(예: 하위 20% 또는 0) 격자를 고르고 읍면동별로 묶는다. 인구 0인 격자는 빼고, 시 경계 띠 안 격자는 따로 표시한다
- 산출물: `산출/낮은지역.csv`, 지도 그림
- 검토할 지도: 낮은 격자 지도(경계 띠와 겹쳐 그림)
- 검토할 표: 낮은 격자가 많은 읍면동 순위(격자 수, 인구, 평균 접근성)
- 확인할 값: 낮은 격자 인구 합과 전체 인구 대비 비율 / 경계 띠 안에 든 비율
