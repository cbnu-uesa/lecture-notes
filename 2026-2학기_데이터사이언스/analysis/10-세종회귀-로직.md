# 10강 예시 — 세종 ㎡당 가격 회귀 로직

7강 끝에 남긴 질문에 답한다.
**"동별 ㎡당 가격이 5.33배 차이 나는데, 위치 때문인가 건축 연한 때문인가?"**

## 설계

| 자리 | 정한 것 | 왜 |
|---|---|---|
| 종속변수 | ㎡당 가격(만원) | 면적 차이를 걷어낸다 |
| 관심 변수 | 신도시 여부 | 세종은 신도시가 **동**, 편입 읍면지역이 **리** 로 이름이 깨끗이 갈린다 |
| 통제 변수 | 건물 나이 = 계약연도 − 건축년도 | 신도시는 새 아파트가 많다. 이것이 혼란변수 후보다 |
| 추가 통제 | 전용면적 | 큰 집이 ㎡당 더 비싼지 확인 |
| 표본 | 전용 60㎡ 초과·취소 제외·건축년도 정상 | 7강과 같은 규칙 |

## 결과 (2026-08-26 · 15,486건)

기술통계로 본 차이
- ㎡당 중앙값 신도시 488 · 편입 215만원
- 건물나이 중앙값 신도시 **4년** · 편입 **12년** → 혼란변수가 실재한다

| 모형 | 신도시 계수 | 나이 | 면적 | R² |
|---|---:|---:|---:|---:|
| 1. 신도시만 | **310** | | | 0.315 |
| 2. + 나이 | **263** | −5.5 | | 0.321 |
| 3. + 면적 | 277 | −4.8 | +1.03 | 0.325 |

**신도시 계수가 310 → 263 으로 15% 줄었다.**
차이의 일부는 건물이 새것이어서였다. 그러나 **대부분은 남는다** —
나이를 같게 맞춰도 신도시가 ㎡당 263만원 비싸다.

## 읽을 때 조심할 것

- **R² 가 0.32 다.** 가격 변동의 3분의 1만 설명한다. 나머지 3분의 2는 이 모형 밖에 있다
  (단지 브랜드, 역과의 거리, 학군, 층, 향, 거래 시점의 시장 상황).
- **나이 통제가 충분하지 않다.** 신도시는 새것일 뿐 아니라 계획도시라
  도로·학교·상가가 함께 들어왔다. "신도시 계수" 는 그 묶음 전체의 효과다.
- **계약 시점을 통제하지 않았다.** 2017~2020 에 가격이 계속 올랐고
  신도시 거래가 뒤로 갈수록 많다. 이 부분이 신도시 계수에 섞여 있다.
- 따라서 **263만원을 "위치의 순수한 값" 이라고 말하면 안 된다.**
  말할 수 있는 것은 "건물 나이만으로는 설명되지 않는다" 까지다.
