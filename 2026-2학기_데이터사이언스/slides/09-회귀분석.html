① 회귀계수

표준화계수

단위를 걷어내서 설명변수 간 효과의 크기를 비교하기 위함

  • 문제: 면적 0.62(만원/㎡) 와 시점 88.3(만원/년)
    → 단위가 달라 크기를 견줄 수 없음
  • 방법 1: y 와 x 를 모두 표준점수로 바꿔 회귀에 투입
    • 표준점수 = (값 − 평균) ÷ 표준편차
  • 방법 2: 원래 계수 × (x 의 표준편차 ÷ y 의 표준편차)
    • 나이: −13.61 × 4.36 ÷ 209.5 = −0.283
  • 읽기: x 가 1표준편차 늘 때 y 가 몇 표준편차 변하나

방법 1과 방법 2의 값은 같음 (세종 다섯 변수로 확인)
→ 계약 시점 > 신도시 > 나이 ≫ 층 · 면적

더미변수(신도시)의 1표준편차는 뜻이 없음. 크기 비교에만 사용

② 유의성

회귀계수의 유의성

계수가 0이 아니라고 말할 수 있는가?

  • 귀무가설: 계수 = 0 (y 와 관계 없음)
    • 참이라면 추정값은 0 주위에 흩어짐 (회색 곡선)
    • 흩어진 폭 = 표준오차
  • t 값: 계수 ÷ 표준오차
    • 0에서 표준오차 몇 개만큼 떨어졌나
    • 면적: 0.62 ÷ 0.087 = 7.15
  • p 값: 귀무가설이 참일 때 이만큼 먼 값이 나올 확률
    • |t| > 1.96 이면 p < .05 (붉은 꼬리)
  • 95% 신뢰구간: 계수 ± 1.96 × 표준오차
    • 구간에 0이 없으면 유의

세종 전용면적 계수 (0.62, 표준오차 0.087)를 예로 그림

가정 ⑤ 다중공선성

다중공선성과 표준오차

겹치는 만큼 계수를 정할 정보가 줄어 표준오차가 커짐

$SE(b_1)=\dfrac{\sigma}{\sqrt{SST_1\,(1-R_1^2)}}$

  • SST₁: x₁ 의 전체 변동
  • R₁²: x₁ 을 종속변수로 놓고 나머지 설명변수로 회귀한 R² (겹치는 비율)
  • SST₁ × (1 − R₁²): x₁ 만의 고유한 변동
    • b₁ 은 이 부분으로만 정해짐 (오른쪽 그림의 붉은 부분)
    • 겹칠수록 분모가 작아져 표준오차 증가
  • VIF = 1 ÷ (1 − R₁²): 표준오차는 √VIF 배

→ 표준오차가 겹침이 없을 때의 1.59배

이항 종속변수와 로지스틱 곡선

  • 회귀가 추정하는 것: x 의 부분집합별 y 의 평균

  • 직선(선형확률모형): 확률이 0 아래 · 1 위로 벗어남
  • 로지스틱 곡선: 0과 1 사이에 머무는 S자

어느 범주에 속하는가를 가리는 문제
→ 회귀라기보다는 분류

④ 로지스틱 회귀

선형회귀에서 로지스틱 회귀로

확률을 승산 · 로짓으로 바꿔 다시 선형식으로 만듦

① 선형회귀

$E(Y_i \mid X_i) = \beta_0 + \beta_1 X_i$

y 가 0 · 1 이면 기대값 = 1일 확률 p

② 문제

$p_i = \beta_0 + \beta_1 X_i$

우변은 −∞ ~ +∞, 확률은 0 ~ 1
→ 0과 1을 벗어남

③ 0 ~ 1 로 묶기

$p_i = \dfrac{e^{\beta_0 + \beta_1 X_i}}{1 + e^{\beta_0 + \beta_1 X_i}}$

로지스틱 함수 (S자 곡선)

④ 승산으로

$\dfrac{p_i}{1 - p_i} = e^{\beta_0 + \beta_1 X_i}$

③을 1 − p 로 나눔
범위 0 ~ ∞

⑤ 로그를 취함

$\ln\!\left(\dfrac{p_i}{1 - p_i}\right) = \beta_0 + \beta_1 X_i$

로짓 · 범위 −∞ ~ +∞
→ 다시 선형식

확률을 직접 추정하지 않고 확률의 로짓을 추정
→ 그래서 로지스틱(로짓) 회귀라고 부름

④ 로지스틱 회귀

확률과 승산

승산(odds) = 일어날 확률 ÷ 일어나지 않을 확률

  • 확률: 전체 가운데 일어난 비율 (0 ~ 1)
  • 승산: 일어난 쪽 대 일어나지 않은 쪽 (0 ~ ∞)
    • 10번 중 8번 일어남: 확률 .8 · 승산 8 ÷ 2 = 4
    • 「4 대 1로 일어나는 쪽이 우세」
  • 승산 = 1: 일어날 확률과 아닐 확률이 같음 (확률 .5)
  • 승산 > 1: 일어나는 쪽이 우세 · < 1: 아닌 쪽이 우세

확률은 1에서 막히지만 승산은 끝없이 커짐
→ 직선으로 놓기 쉬운 척도

승산비

승산비(odds ratio) = 두 집단의 승산의 비. 1 이면 차이 없음

→ 접종하면 확진의 승산이 1/8 로 줄어듦

로짓과 로지스틱 회귀식

로짓 = ln(승산). 확률 대신 로짓을 직선으로 놓음

척도범위직선으로 놓으면
확률 p0 ~ 10과 1을 벗어남
승산 p ÷ (1 − p)0 ~ ∞0 아래로 벗어남
로짓 ln(승산)−∞ ~ +∞벗어날 곳이 없음

ln( p ÷ (1 − p) ) = b₀ + b₁x₁ + b₂x₂ + …

추정: 최우추정법 · 계수 검정: Wald 검정

  • b 의 뜻: x 가 1 늘 때 로짓이 b 만큼 변함
  • 로짓이 b 늘면: 승산은 exp(b) 배
    • 로그의 덧셈 = 원래 값의 곱셈
  • exp(b) = 승산비: x 가 1 큰 집단과 아닌 집단의 승산의 비

세종 건물 나이 (나이 하나만 넣은 모형): b = −0.254
exp(−0.254) = 0.78
→ 1년 오래될수록 고가의 승산 0.78배 (22% 감소)

로지스틱 모형의 적합도

우도비 검정 → 의사 R² → 분류표 순서로 봄

  • 우도비 검정: 선형회귀의 F 검정에 해당
    • 세종: χ² = 8,092, p < .001 → 쓸 수 있는 모형
  • McFadden 의사 R²: 0.2 이상이면 충분
    • 세종: .377 (OLS 의 R² 와 계산이 다름)
  • 분류표: 예측확률 > 0.5 이면 1 로 분류해 실제와 비교
    • 민감도: 고가를 고가라고 맞힌 비율
    • 특이도: 아닌 것을 아니라고 맞힌 비율

  • 언제: 같은 개체를 여러 시점에 관측 (도시 × 연도)
  • 판단: 고정효과 vs 확률효과 → 하우스만 검정
  • 세종: 단지 × 연도 평균으로 바꾸면 패널

  • 판단: LM 검정 → 공간시차 vs 공간오차

9강 PDF 를 위키에 넣고, 그 내용으로 AI 가 낸 문제를 풂

  3. 한 문제씩 풂: 답하기 전에는 정답을 보여 주지 말라고 함. 답은 자기 말로

과제 2: 자기 연구대상의 회귀분석

자기 연구대상에서 회귀분석으로 풀 문제를 만들고, 회귀 가정 진단까지 마침

  1. 문제 정의: 연구질문 → 종속변수 y 하나와 설명변수 x 셋 이상
    • 왜 이 x 가 y 를 설명한다고 보는가 한 줄씩
  2. 모형 선택: y 의 형태 → 순서도에서 고른 모형과 이유 (선형 · 로지스틱 …)
  3. 추정과 해석: 결과표 (계수 · 표준오차 · t · p · 95% 구간 + F · R²)
    • 계수마다 「다른 조건이 같다면」 해석 · 표준화계수로 크기 비교
  4. 회귀 가정 진단: 여섯 가정의 「지표 · 판단 · 대응」 표
    • 위배된 가정은 대응을 적용한 모형으로 다시 추정해 전후를 비교
