① 회귀계수

회귀분석: 목적과 정의

x 에 대응하는 y 의 「부분집합별」 평균값을 추정하는 통계적 방법

  • 종속변수 y: 알고자 하는 변수 (㎡당 가격)
  • 설명변수 x: y 를 추정하는 데 쓰는 변수 (나이, 신도시 여부 …)
  • 최소제곱법: 잔차(관측치 − 추정치)의 제곱합을 최소로 만드는 계수
  • 단순 / 다중회귀: 설명변수가 하나 / 둘 이상

→ 다중회귀의 목적: ① y 를 더 잘 추정 ② 한 변수의 (가급적) 순수한 영향

② 유의성

계수는 표본에서 나온 값. 다른 표본이면 다른 값

② 유의성

계수가 0이 아니라고 말할 수 있는가

회귀계수 = 확률변수 → 표준오차로 유의성 판단

  • 귀무가설: 계수 = 0 (y 와 관계 없음)
  • t 값: 계수 ÷ 표준오차 (0에서 표준오차 몇 개만큼 떨어졌나)
  • p 값: 계수가 정말 0일 때 이만큼 떨어진 값이 나올 확률
  • 95% 신뢰구간: 대략 계수 ± 2 × 표준오차

→ |t| > 1.96 · p < .05 · 구간에 0 없음 → 유의

세종: 다섯 변수 모두 기준 통과 (오른쪽)

출처: 고급도시교통통계분석 7강 p.42·44·46. p 값·신뢰구간 풀이는 이 강의에서 보탬

가정 ① 선형성

선형성: x 와 y 의 관계가 직선인가

x 가 1 늘 때 y 의 변화가 어디서나 같음

  • 깨지면: 휜 관계를 직선으로 요약 → 계수 편향
  • 진단:
    • 잔차도: 잔차가 0 주위에 무늬 없이 흩어져야 함
    • RESET 검정: 추정치의 제곱을 넣어 유의하면 비선형
  • 위배 시:
    • 로그 · 제곱근 변환, 제곱항(다항회귀)
    • 잔차의 무늬 = 빠진 변수의 흔적 → 변수 추가

→ 세종: 나이별 잔차 평균이 오르내림 · RESET p < .001 → 선형성 위배

가정 ② 등분산성

등분산성: 오차의 퍼짐이 어디서나 같은가

오차의 분산이 x 와 관계없이 일정 (등분산) ↔ 이분산

  • 깨지면: 계수는 그대로, 표준오차 · p 값이 틀림
  • 진단:
    • 잔차도: 한쪽으로 갈수록 넓어지는 깔때기 → 이분산
    • Breusch-Pagan 검정: p < .05 → 이분산
  • 위배 시:
    • y 변환 (로그 · 제곱근 · 역수)
    • 강건표준오차 (White) · 가중최소제곱(WLS)

→ 세종: 비쌀수록 퍼짐 · BP p < .001 → 이분산

→ ln(가격)으로 바꾸면 퍼짐 감소. 남은 이분산은 강건표준오차로

표본 600건 · 원래 모형

가정 ③ 독립성

독립성: 관측치의 오차끼리 서로 무관한가

한 관측치의 오차가 다른 관측치의 오차와 관련 없음

  • 깨지면: 실제 정보량 < 관측치 수 → 표준오차를 작게 잡음
  • 진단:
    • 더빈-왓슨: 2 근처면 독립, 0 쪽이면 양의 자기상관
    • 자료 구조: 같은 단지 · 같은 시기 · 이웃 지역
  • 위배 시:
    • 군집 표준오차 (묶음 단위로 계산)
    • 다수준 · 패널 · 공간회귀 모형

→ 세종: 133개 단지에 거래가 묶임 · DW 0.89 → 독립성 위배

→ 단지 군집 표준오차: t 가 크게 줄고 면적은 유의하지 않음 (p .29)

가정 ④ 정규성

정규성: 오차가 정규분포를 따르는가

오차가 평균 0 인 정규분포를 따름

  • 깨지면: 계수의 분포를 몰라 t · F 검정이 흔들림
    • 표본이 크면 중심극한정리로 영향 작음
  • 진단:
    • Q-Q 그림: 점이 대각선 위에 있으면 정규
    • 왜도 0 · 첨도 3 근처 · Shapiro 검정 p ≥ .05
  • 위배 시:
    • 오른쪽 꼬리 → 로그 변환
    • 표본 늘리기

→ 세종: 오른쪽 끝이 위로 휨 · 왜도 0.84 → 정규성 위배

→ 로그 변환 후 대각선에 붙음 (왜도 −0.01)

가정 ⑤ 다중공선성

다중공선성: 설명변수끼리 겹치지 않는가

설명변수 사이에 강한 선형관계가 없음

  • 깨지면: 표준오차↑ → 유의성 사라짐 · 계수가 표본마다 크게 흔들림
  • 진단:
    • 설명변수 간 상관계수
    • VIF = 1 ÷ (1 − 그 변수를 나머지로 회귀한 R²)
  • 판단: VIF 5~10 의심 · 10 이상 심각
  • 위배 시: 중요하지 않은 쪽 빼기 · 합치기(비율·지수) · 자료 추가
    • 예측이 목적이면 크게 문제 삼지 않음

→ 세종: VIF 최대 2.60 → 문제 없음

가정 ⑥ 이상치 · 영향점

영향점: 몇 개의 점이 직선을 끌고 가는가

  • 이상치: 회귀선에서 크게 벗어난 점 (잔차가 큼)
  • 영향점: 빼면 계수가 크게 바뀌는 점 (x 의 극단일수록)
  • 진단:
    • 표준잔차 ±3 이상
    • Cook 거리: 레버리지 + 잔차. 1 이상 의심 (4/n 을 쓰기도)
  • 위배 시: 입력 오류인지 먼저 확인 → 신중히 제거 · 변환 · 강건회귀

→ 세종: Cook 최대 0.005 → 영향점 없음 (4/n 초과 729건도 계수를 움직이지 못함)

  • 직선(선형확률모형): 확률이 0 아래 · 1 위로 벗어남
    • 세종 다섯 변수 모형: 1,235건이 0~1 밖
  • 로지스틱: 확률 대신 로짓을 직선으로 → 곡선이 0~1 안에 머묾

→ 「회귀라기보다는 분류의 문제」 (어느 범주에 속하는가)

출처: 고급도시교통통계분석 10강 p.3

점 300건은 위아래로 흩어 겹침을 풂 · 선은 나이 하나만 넣은 모형

④ 로지스틱 회귀

확률 → 승산 → 로짓

  • 승산(odds): 일어날 확률 ÷ 일어나지 않을 확률 (0 ~ ∞)
  • 로짓: ln(승산) (−∞ ~ +∞) → 직선으로 놓을 수 있음
  • 승산비(OR): 두 집단의 승산의 비. 1 이면 차이 없음

ln( p ÷ (1 − p) ) = b₀ + b₁x₁ + b₂x₂ + …

→ b: x 가 1 늘 때 로그 승산의 변화 · exp(b) = 승산비

추정: 최우추정법 · 계수 검정: Wald 검정

출처: 고급도시교통통계분석 10강 p.4~8·17·21·33

원 강의의 백신 예

접종미접종
확진28
비확진84
승산2/8 = 0.258/4 = 2.0

→ 승산비 = 0.25 ÷ 2.0 = 0.125 (접종 시 확진 승산 1/8)

④ 로지스틱 회귀

로지스틱 모형의 적합도

  • 우도비 검정: 선형회귀의 F 검정에 해당
    • 세종: χ² = 8,092, p < .001
  • McFadden 의사 R²: 0.2 이상이면 충분
    • 세종: .377 (OLS 의 R² 와 계산이 다름)
  • 분류표: 예측확률 > 0.5 → 1 로 분류해 실제와 비교
  • ROC · AUC: 0.7 이상이면 수용 가능

④ 모형 선택

④ 모형 선택

오차가 묶여 있을 때 쓰는 세 모형

다수준 모형

  • 언제: 관측치가 상위 집단에 속함 (아파트 → 단지 → 동)
  • 판단: 집단 내 상관(ICC) 5% 미만 → 일반 회귀로 충분
  • 세종: 133개 단지 → 군집 표준오차의 다음 단계

패널 모형

  • 언제: 같은 개체를 여러 시점에 관측 (도시 × 연도)
  • 판단: 고정효과 vs 확률효과 → 하우스만 검정
  • 세종: 단지 × 연도 평균으로 바꾸면 패널

공간회귀 모형

  • 언제: 가까운 곳끼리 닮음 (공간적 자기상관)
  • 판단: LM 검정 → 공간시차 vs 공간오차
  • 세종: 단지 좌표로 잔차의 Moran's I 부터 (7강)

출처: 고급도시교통통계분석 11강 p.4~46

실습: 회귀 → 진단 → 로지스틱

1. 회귀

㎡당 가격을 신도시 여부·건물 나이·전용면적·층·계약 시점으로 회귀해 줘. 계수·표준오차·t·p·95% 신뢰구간 표와 R²·수정 R²·F 를 보여 줘.

계수마다 「다른 조건이 같다면」으로 시작하는 해석 문장을 한 줄씩 쓰고, 표준화계수도 함께 보여 줘.

확인할 값: 신도시 193.2 · 나이 −13.6 · 시점 88.3 · R² .548

3. 로지스틱

㎡당 가격이 중앙값을 넘으면 1인 변수를 만들어 같은 다섯 변수로 로지스틱 회귀를 해 줘. 승산비와 95% 구간, 우도비 검정, McFadden 의사 R², 기준값 0.5 의 분류표를 보여 주고 승산비마다 해석 문장을 써 줘.

확인할 값: 승산비 신도시 41.4 · 나이 0.729 · 의사 R² .377 · 정분류율 79.4%

2. 가정 진단

이 회귀의 여섯 가정(선형성·등분산성·독립성·정규성·다중공선성·영향점)을 점검해 줘. 잔차도, 나이별 잔차 평균, Q-Q 그림을 그리고 RESET, Breusch-Pagan, 더빈-왓슨, 왜도·첨도, VIF, Cook 거리를 구해 줘.

같은 단지(시군구 + 단지명) 거래는 오차가 닮았을 수 있으니 단지 군집 표준오차와 일반 표준오차를 나란히 보여 줘.

가정마다 「지표 · 판단 · 대응」을 표로 정리하고, ln(㎡당 가격) 모형으로 다시 진단해 줘.

확인할 값: RESET p<.001 · BP 1,465 · 왜도 0.84 · VIF 최대 2.6 · 단지 133개 · 군집 표준오차에서 면적 p .29
