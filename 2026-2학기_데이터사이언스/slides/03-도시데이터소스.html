그 증거의 원료는 어디에 있는가?

  • 지난주 문제정의서에 "이런 데이터가 필요하다" 고 적었다
  • 그게 실제로 있는가
  • 있다면 어떻게 손에 넣는가

국내 데이터는 크게 일곱 군데에 있다

어디무엇이 있나받는 방식
KOSIS 국가통계포털인구·가구·산업 통계표화면 조회 · CSV
공공데이터포털부처·지자체가 여는 거의 전부파일 · API
SGIS 통계지리정보격자·행정동 단위 공간통계화면 · API
실거래가 공개시스템부동산 매매·전월세 거래CSV · API
KTDB 교통DB통행량·OD·network신청 후 제공

지자체 데이터포털그 도시에만 있는 것제각각

오늘은 이 중 실거래가 하나를 세 방식으로 받아 본다. 방식을 익히면 나머지도 같다.

같은 데이터를 얻는 세 가지 방식

API 는 어렵지 않다 — 주소에 조건을 붙이는 것이다

국토교통부_아파트 매매 실거래가 자료 · getRTMSDataSvcAptTrade

붙이는 조건뜻예
serviceKey나를 알아보는 열쇠포털에서 발급받는다
LAWD_CD지역 — 법정동코드 앞 5자리43111 (청주시 상당구)
DEAL_YMD계약 연월202608

조건 셋을 바꾸면 다른 지역·다른 달이 나온다. 열두 달을 받으려면 열두 번 부르면 된다 — 그것이 프로그램이 할 일이다.

법정동코드는 행정표준코드관리시스템(code.go.kr)에서 찾는다. 청주 나머지 세 구는 실습에서 직접 찾는다 — 코드를 찾는 일 자체가 오늘 배울 기술이다.

받고 나서 겪는 것들

겪는 것무슨 일인가
글자가 깨진다공공기관 CSV 는 EUC-KR 인 경우가 많다. 엑셀은 열리는데 파이썬에서 깨지면 이것이다
숫자가 글자다거래금액에 쉼표가 들어 있다 — "1,250" 은 숫자가 아니다
지역이 안 맞는다행정동과 법정동은 다르다. 통계는 행정동, 부동산은 법정동인 경우가 많다
기간이 비어 있다거래가 없는 달은 행이 아예 없다. 0 이 아니라 없음이다
단위가 다르다거래금액은 만원, 면적은 ㎡. 평으로 바꾸면 어디선가 어긋난다

전부 클로드가 처리해 준다. 다만 처리했다는 사실을 알고 있어야 결과가 이상할 때 어디를 볼지 안다.

실습

청주 상당구 실거래가를 세 방식으로 받기 — 약 1시간 30분

실습 — 오늘 만들 것

대상

청주시 상당구 아파트 매매 실거래가 · 최근 12개월

원도심이 있는 구다. 2주차에 본 문제와 이어지고, 4~6주차 내내 이 파일을 쓴다.

왜 세 번이나 받나

  • 같은 데이터가 나와야 내가 제대로 받았는지 알 수 있다
  • 세 방식의 손이 가는 정도를 몸으로 비교하게 된다
  • ③ 이 편하다는 것을 알되, ①②를 해 봐야 ③의 결과를 의심할 수 있다

실습 ① — 손으로 받는다 20분

  1. 국토교통부 실거래가 공개시스템 rt.molit.go.kr 에 들어간다
  2. 아파트 → 매매 → 지역을 충청북도 청주시 상당구로, 기간을 최근 12개월로 지정한다
  3. 화면에서 결과를 훑어본다 — 몇 건인가
  4. CSV 로 내려받아 열어 본다. 열 이름과 단위를 확인한다

메모해 둘 것: 전체 건수. ②③의 결과를 이것과 맞춰 본다.

조건을 하나씩 바꿔 보면 무엇이 어떻게 걸러지는지 보인다. API 의 파라미터가 곧 이 화면이다.

실습 ② — 인증키를 받는다 35분

  1. data.go.kr 회원가입 (공공데이터포털)
  2. "국토교통부_아파트 매매 실거래가 자료" 를 찾아 활용신청한다. 자동 승인이라 곧 쓸 수 있다
  3. 마이페이지에서 인증키(serviceKey)를 확인한다. 상세 화면에 요청 주소와 파라미터 설명이 함께 있다
  4. code.go.kr/stdcode/regCodeL.do 에서 법정동코드를 찾는다 — 청주시 상당구 4311100000 → 앞 5자리 43111
  5. 서원구·흥덕구·청원구의 코드도 직접 찾아 적어 둔다

인증키는 남에게 보이지 않는다. 화면 공유나 제출물에 그대로 넣지 않는다.

실습 ③ — 맡긴다 20분

프롬프트 예시

"공공데이터포털의 국토교통부 아파트 매매 실거래가 API를 쓰려고 해. 인증키는 따로 알려줄게.

지역은 청주시 상당구(LAWD_CD 43111), 기간은 최근 12개월이야. 열두 달을 각각 받아서 CSV 한 장으로 합쳐 줘.

합치기 전에 어떻게 받아서 어떻게 합칠지 먼저 알려 줘. 다 받은 뒤에는 달마다 몇 건이 왔는지 표로 보여 줘."

마지막 두 문장이 핵심이다. 받기 전에 방법을, 받은 뒤에 건수를 요구한다 — 그래야 ①에서 센 건수와 맞춰 볼 수 있다.

건수가 다르면 멈춘다. 기간 해석이 다른지, 취소 거래를 포함했는지 물어본다.
