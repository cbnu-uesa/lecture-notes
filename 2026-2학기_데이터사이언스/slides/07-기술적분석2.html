단계구분도: 목적과 정의

구역마다 값을 몇 개의 계급으로 나누고 계급마다 색을 칠한 지도

영어로 choropleth map. 행정동 · 격자처럼 면이 단위다

  • 구역: 경계로 둘러싸여 값 하나를 갖는 면. 행정동 · 격자 등
  • 계급: 값의 범위를 나눈 구간. 계급마다 색 하나를 칠함
  • 등간 분류: 최솟값에서 최댓값까지를 같은 폭으로 나눔
  • 분위 분류: 계급마다 들어가는 구역 수가 같도록 나눔
  • 자연분류(Jenks): 계급 안 값들의 편차 제곱합이 가장 작도록 나눔

필요한 자료: 구역(경계) + 구역마다 값 하나

→ 값의 지역 차이가 한눈에 보임. 다만 계급을 어떻게 나누느냐로 지도가 달라짐

커널밀도추정: 목적과 정의

점마다 둥근 언덕을 하나씩 얹고 모두 더해 만든 매끈한 밀도면

영어로 Kernel Density Estimation. 경계가 없는 점 자료를 면으로 바꿈

  • 밀도: 단위 면적에 든 점의 개수. 광양은 km² 당 충전소 수
  • 커널: 점 하나에 얹는 언덕의 모양을 정한 함수. 가우스 커널은 종 모양
  • 대역폭(bandwidth): 언덕이 퍼지는 폭. 넓을수록 밀도면이 매끈해짐
  • 밀도면: 지도 위 위치마다 계산한 밀도를 이어 붙인 면

필요한 자료: 점 좌표 + 언덕의 폭(대역폭)

→ 점이 얼마나 촘촘한가를 행정경계에 묶이지 않고 봄

방법 2 / 6

커널밀도추정: 어떻게 작동하나

  1. 점마다 언덕을 얹음
    점에서 멀어질수록 낮아지는 종 모양
  2. 언덕의 폭을 정함
    그것이 대역폭. 광양은 1km
  3. 모두 더함
    점이 몰린 곳은 언덕이 겹쳐 높아짐
  4. 높이를 색으로
    지도 위에 칠함

→ 대역폭이 결과를 바꿈. 좁으면 점마다 따로, 넓으면 하나로 뭉개짐

같은 점 다섯 개. 대역폭만 다름

방법 3 / 6

전역 공간자기상관 — Moran's I: 목적과 정의

이웃한 구역끼리 값이 얼마나 비슷한가를 숫자 하나로 측정한 것

  • 공간자기상관: 가까운 구역끼리 값이 서로 닮은 정도
  • 이웃: 경계가 맞닿거나 정한 거리 안에 있는 구역
  • 공간가중행렬: 구역 쌍마다 이웃인지를 적은 표. 이웃이면 1, 아니면 0
  • I 의 부호: 양수는 비슷한 값끼리 뭉침 · 0 근처는 아무렇게나 흩어짐 · 음수는 높고 낮은 값이 엇갈림
  • z 점수: I 가 아무렇게나 흩어졌을 때의 기대값에서 표준편차 몇 개만큼 떨어졌나

필요한 자료: 구역 + 값 + 누가 누구의 이웃인지 (공간가중행렬)

→ 지도를 보고 「뭉쳐 보인다」 고 느낀 것을 검정할 수 있는 숫자로 바꿈

방법 3 / 6

Moran's I: 어떻게 작동하나

  1. 이웃을 정함
    광양은 격자 중심 사이 150m 이내 — 상하좌우
  2. 평균에서 얼마나 벗어났나 를 칸마다 구함
  3. 이웃끼리 그 편차를 곱해 더함
    같은 쪽으로 벗어나면 양수가 쌓임
  4. 표준화하고 z 로 유의성을 봄
    이 과목은 정규근사 — 난수를 쓰지 않음

I = (n / S₀) · ΣᵢΣⱼ wᵢⱼ zᵢ zⱼ / Σᵢ zᵢ²

zᵢ 평균에서의 편차 · wᵢⱼ 이웃이면 1 · S₀ 이웃 쌍의 수

같은 개수의 진한 칸. 놓인 자리만 다름 — I 는 이 그림에서 계산한 값

방법 4 / 6

국지 공간자기상관 — LISA: 목적과 정의

칸마다 내 값과 이웃의 값을 견줘 뭉침이 어디서 생기는지 짚는 것

영어로 Local Indicators of Spatial Association. Moran's I 를 칸 하나씩 나눠 본 것

  • 공간시차(spatial lag): 한 칸의 이웃들이 가진 값의 평균
  • 국지 I: 내 표준화 값 × 이웃의 표준화 값 평균. 양수면 이웃과 닮음
  • HH · LL: 높은(낮은) 칸이 높은(낮은) 이웃에 둘러싸인 덩어리
  • HL · LH: 이웃과 반대로 높거나 낮은 칸. 공간 이상치라고도 함

필요한 자료: Moran's I 와 같음

→ 「뭉쳐 있다」 를 넘어 어디가 높은 덩어리, 어디가 낮은 덩어리, 어디가 튀는 곳인지

방법 4 / 6

LISA: 어떻게 작동하나

  1. 내 값을 표준화: 평균보다 높나 낮나
  2. 이웃 평균을 표준화: 이웃은 높나 낮나
  3. 둘을 곱함: 그 칸의 국지 I
  4. 네 사분면으로 나눔

→ HH · LL 은 덩어리, HL · LH 는 주변과 다른 튀는 칸

방법 4 / 6

LISA: 적용 사례

유형칸비율

HH 는 남쪽 시가지 몇 곳에 덩어리로 모임. 가까운 충전소 이름으로 보면 광양읍 · 중마동 · 광영동 쪽

LH 는 시가지 가장자리 — 사람 많은 동네 바로 옆의 빈 칸

주: 칸마다 유의성 검정은 하지 않고 사분면으로만 나눴음

방법 5 / 6

핫스팟 분석 — Getis-Ord Gi*: 목적과 정의

한 칸과 그 이웃의 합이 전체에서 기대한 것보다 유의하게 큰지를 z 로 측정한 것

  • 핫스팟: Gi* 가 유의하게 큰 칸. 높은 값이 몰려 있는 곳
  • 콜드스팟: Gi* 가 유의하게 작은 칸. 낮은 값이 몰려 있는 곳
  • Gi 와 Gi*: Gi* 는 자기 칸을 합에 넣고, Gi 는 이웃만 더함
  • 유의 기준: |z| 가 1.96 을 넘으면 95%, 2.58 을 넘으면 99% 에서 유의

필요한 자료: Moran's I 와 같음

→ LISA 가 네 유형을 나눈다면 Gi* 는 뜨거운 곳 하나에 집중함

방법 5 / 6

Gi*: 어떻게 작동하나

  1. 나와 이웃을 한 묶음으로: Gi* 는 자기 자신을 포함함
  2. 묶음의 합을 구함
  3. 전체 평균으로 기대한 합과의 차이를 구함
  4. 표준화해 z 로: |z| > 2.58 이면 99% 에서 유의

Gᵢ* = (Σⱼ xⱼ − x̄·w) / ( s · √((n·w − w²)/(n−1)) )

합은 나와 이웃 w 칸에 대해 · x̄ 전체 평균 · s 전체 표준편차

가운데 칸의 묶음: 자기 자신 + 상하좌우 넷

방법 5 / 6

Gi*: 적용 사례

핫스팟 (z > 2.58)

콜드스팟 (z < −2.58)

결과를 읽기 전에 볼 한계 둘

콜드스팟 0 은 자료의 성질: 인구는 0 아래로 못 가고 0 이 절반이라 낮은 쪽으로는 더 낮아질 수 없음

방법 6 / 6

밀도기반 공간군집 — DBSCAN: 목적과 정의

반경 안에 점이 충분히 모인 곳을 덩어리로 잇고, 어디에도 끼지 못한 점은 잡음으로 남기는 것

6강 K-means 와 달리 덩어리 개수를 미리 정하지 않음. 모양도 둥글 필요가 없음

  • eps: 이웃으로 볼 반경
  • minPts: 핵심점이 되려면 반경 안에 있어야 하는 최소 점 수 (자기 포함)
  • 핵심점: 반경 eps 안에 minPts 개 이상의 점이 있는 점
  • 경계점: 스스로는 모자라지만 어떤 핵심점의 반경 안에 드는 점
  • 잡음: 핵심점도 경계점도 아닌 점

필요한 자료: 점 좌표 + 반경 eps + 최소 점 수 minPts

→ 위치만으로 덩어리와 외톨이를 가름

방법 6 / 6

DBSCAN: 어떻게 작동하나

  1. 반경 eps 를 정함: 광양은 700m
  2. 핵심점: 반경 안에 자기 포함 minPts(3) 이상
  3. 경계점: 핵심점의 반경 안에 들지만 스스로는 모자람
  4. 잡음: 어느 쪽도 아님
  5. 이어진 핵심점과 경계점이 한 덩어리

점의 구분은 그림 속 좌표로 실제로 계산한 것

  • 쓰는 경우: 어떤 목적과 자료에서 쓰나
  • 다른 방법과의 차이: 같은 목적의 다른 방법과 무엇이 다른가.
    이웃을 어떻게 정하느냐에 따라 결과가 어떻게 바뀌나
  • 장점과 단점: 무엇을 잘 보여 주고 무엇을 놓치나.
    흔히 저지르는 잘못은 무엇인가

2. 자기 데이터에 적용해 보고서로 정리한다

  1. 목적을 한 문장으로 적음: 「어디에 무엇이 몰려 있는가」
  2. 방법을 고르고 이유를 적음: 순서도의 어느 갈림을 탔나
  3. 정한 값을 적음: 분류법 · 대역폭 · 이웃 반경 · eps 처럼 결과를 바꾸는 것
  4. 적용하고 결과를 봄: AI 에게 로직을 요구하고 사람이 검증함
