설치와 CLAUDE.md

 

채팅창과 무엇이 다른가?

  • 지난주에 받은 CSV 를 채팅창에 올릴 수도 있다
  • 그런데 파일이 열 개면? 결과를 저장하려면?
  • 같은 분석을 다음 달에 또 해야 한다면?

클로드 코드

터미널에서 내 폴더의 파일을 직접 읽고, 쓰고,
프로그램을 실행하는 클로드

→ 파일을 올리고 내려받는 왕복이 없다.
   "저 폴더의 CSV 를 분석해서 결과를 저장해 줘" 가 한 문장으로 끝난다

같은 일을 시키면 이렇게 갈린다

웹 대화창클로드 코드
파일 주기하나씩 올린다폴더를 가리키면 알아서 읽는다
결과 받기화면에서 복사한다파일로 저장된다
중간 산출물남지 않는다폴더에 쌓인다
다시 하기처음부터 다시 설명규칙을 적어 두면 재현된다
안전할 게 없다무엇을 허용할지 내가 정한다

오늘 위 세 줄과 네 번째 줄까지 간다. 마지막 줄은 설치하면서 바로 만난다.

내 컴퓨터를 만지게 하는 일이다

그래서 물어본다 — 승인은 내가 한다

터미널
> cheongju-apt.csv 를 읽고 동별 평균을 내 줘

  파일을 읽겠습니다: cheongju-apt.csv
  허용하시겠습니까? (y/n)
  • 읽기는 대체로 안전하다
  • 쓰기·삭제·실행은 무엇을 지우는지 보고 승인한다
  • 승인하기 전에 무엇을 하려는지 한 줄 읽는 습관을 들인다

실습용 폴더를 따로 만들어 쓰면 사고가 나도 그 폴더 안에서 끝난다. 중요한 파일이 있는 폴더에서 시작하지 않는다.

이 수업의 습관 — 코드 말고 로직부터

"코드는 아직 쓰지 말고,
어떤 자료를 어떻게 걸러 무엇을 계산할지 먼저 알려 줘"

→ 1강에서 말한 원칙을 실제로 부르는 문장이다.
   여기서 판단을 확인하지 않으면 결과가 나온 뒤에는 확인할 수 없다

바로 시키면 무엇을 놓치나

"동별 평균 가격을 내 줘" 라고만 하면, AI 가 대신 정해 버리는 것들

몰래 정해지는 것왜 문제인가
어떤 거래를 포함할지소형·초고가를 넣고 빼는 것만으로 순위가 바뀐다
평균이냐 중앙값이냐거래 몇 건이 평균을 통째로 끌고 간다
가격이냐 ㎡당 가격이냐면적이 다르면 가격 비교는 뜻이 없다
거래가 적은 동을 어찌할지3건짜리 동이 1위가 되어도 그건 우연이다

전부 도시를 아는 사람이 정해야 하는 것이다. AI 는 물어보지 않으면 그냥 정한다.

그런데 내일 다시 하면 답이 달라진다

  • 오늘 정한 그 규칙들 — 면적 하한, 중앙값, 최소 건수
  • 새 대화를 열면 클로드는 그것을 모른다
  • 같은 요청에 다른 답이 나오는 분석은 증거가 될 수 없다

클로드가 기억하는 범위

CLAUDE.md

작업 폴더에 두는 규범 문서.
클로드가 그 폴더에서 일할 때마다 먼저 읽는다

→ "이 프로젝트에서는 이렇게 한다" 를 적어 두는 곳이다.
   사람이 읽어도 그대로 말이 되는 문서여야 한다

무엇을 적나

적을 것

  • 데이터가 무엇이고 어디서 왔는지
  • 단위와 기준 시점
  • 판단이 갈리는 자리의 결정과 이유
  • 결과를 어떤 형식으로 낼지
  • 하지 말아야 할 것

적지 않을 것

  • 한 번만 쓸 요청
  • 인증키 같은 비밀
  • 클로드가 이미 아는 일반 지식
ds2026/CLAUDE.md
# 청주 상당구 실거래가 분석

## 데이터
cheongju-apt.csv — 국토부 실거래가 API
2025.10~2026.09 계약분, 상당구(43111)
금액 만원 · 면적 ㎡

## 분석 규칙
- 전용면적 60㎡ 초과만 쓴다
  소형은 임대 목적이 섞여 성격이 다르다
- 가격은 ㎡당 가격으로 비교한다
- 대표값은 중앙값. 평균도 함께 낸다
  고가 거래 몇 건이 평균을 끈다
- 거래 10건 미만인 동은 표에서 뺀다
  대신 뺀 동을 아래에 적는다

## 하지 않는 것
- 원본 CSV 를 고쳐 덮어쓰지 않는다

어디에 두느냐로 적용 범위가 갈린다

위치적용 범위여기 적을 것
./CLAUDE.md이 프로젝트 데이터 규칙·산출 규격. 팀과 공유한다
~/.claude/CLAUDE.md내 모든 프로젝트 글쓰기 취향, 늘 지켜야 할 개인 규칙

프로젝트 것과 개인 것을 섞지 않는다. "우리 데이터는 60㎡ 초과만" 은 프로젝트, "표는 웬만하면 쓰지 마" 는 개인이다.

하위 폴더에도 둘 수 있다. 큰 저장소에서 폴더마다 규칙이 다를 때 쓴다.

CLAUDE.md 를 관리해 주는 플러그인

claude-md-management 는 Anthropic 공식 마켓플레이스에 있는 플러그인이다. 도구 둘이 들어 있다.

설치
/plugin 으로 마켓플레이스에서 찾아 설치한다
설치 뒤 /reload-plugins 가 필요할 수 있다

플러그인이 무엇인지는 다음 주(5강)에 제대로 다룬다. 오늘은 CLAUDE.md 를 손보는 도구로만 쓴다.

도구언제 쓰나
claude-md-improver
스킬		 CLAUDE.md 가 지금 코드·데이터와 어긋나지 않는지 점검한다. "내 CLAUDE.md 좀 봐 줘" 라고 하면 된다
/revise-claude-md
명령		 작업이 끝난 뒤 이번에 새로 정한 것을 CLAUDE.md 에 반영한다

아래쪽이 이 수업에 특히 맞는다 — 실습 중에 정한 판단을 잊기 전에 옮긴다.

주의 — 이유 없는 규칙은 지켜지지 않는다

이렇게 쓰면무슨 일이 생기나
"60㎡ 초과만 쓴다"
이유가 없다		 석 달 뒤에 왜 그랬는지 몰라 그냥 고쳐 버린다. 한 줄이라도 이유를 붙인다
규칙이 마흔 줄대화를 열 때마다 읽히므로 길수록 비용이 든다. 절차가 길어지면 스킬로 뺀다 (5강)
인증키를 적어 둔다CLAUDE.md 는 대개 저장소에 함께 올린다. 비밀은 절대 넣지 않는다
한 번 쓰고 안 고친다데이터가 바뀌면 규칙도 낡는다. claude-md-improver 로 주기적으로 점검한다

실습

설치 · 첫 분석 · 재현되게 만들기 — 약 1시간 30분

실습 ① — 설치와 첫 대화 20분

  1. 터미널을 연다 (맥 터미널 · 윈도우 PowerShell)
  2. 공식 문서 code.claude.com/docs 의 설치 안내를 따른다. 버전마다 달라지므로 화면에 적힌 대로 한다
  3. 로그인한다 — 2주차에 만든 계정
  4. 실습 폴더 ds2026/ 을 만들고 3주차 cheongju-apt.csv 와 출처 문서를 넣는다. 그 폴더에서 claude 를 실행한다
  5. "이 폴더에 뭐가 있어?" 라고 물어본다

막히면 오류 메시지를 그대로 클로드에게 붙여 넣는다.

실습 ② — 로직만 요구한다 25분

프롬프트

"이 폴더의 cheongju-apt.csv 로 청주 상당구의 동별 ㎡당 가격을 비교하고 싶어.

코드는 아직 쓰지 마. 어떤 자료를 어떻게 걸러 무엇을 계산할지 로직을 문서로 먼저 보여 줘.

판단이 필요한 자리는 선택지를 같이 적어 줘 — 네가 정하지 말고 내가 고르게."

받은 로직을 읽고 다섯 가지를 정한다

전용면적 하한 · 이상 거래 처리 · 평균이냐 중앙값이냐 · 거래 적은 동 · 기간을 나눌 것인가. 정한 것과 이유를 메모해 둔다 — 실습 ④의 재료다.

실습 ③ — 실행하고, 어긋남을 본다 20분

  1. "정한 대로 하고 결과를 표로 저장해 줘" 라고 시킨다. 결과를 로직 문서와 대조한다
  2. 이제 새 대화를 연다 (/clear 또는 새 창)
  3. 같은 요청을 글자 그대로 다시 한다
  4. 두 결과를 나란히 놓고 본다

면적 하한이 사라졌거나 중앙값이 평균으로 바뀌었을 것이다. 클로드가 틀린 것이 아니다 — 내가 정한 것을 말해 주지 않았을 뿐이다.

이 화면을 캡처해 둔다. 제출물의 '전(前)' 이다.

실습 ④ — 규칙을 적고 재현시킨다 25분

  1. 실습 ②에서 메모한 판단 다섯을 CLAUDE.md 로 옮긴다. 규칙마다 이유를 한 줄씩
  2. 초안을 보여 주고 묻는다 — "아직 애매해서 네가 임의로 정하게 될 자리가 어디야? 규칙을 새로 만들지는 말고 어디가 비었는지만 알려 줘"
  3. 또 새 대화를 열어 같은 요청을 한다. 이번에는 같은 결과가 나와야 한다
  4. 다르면 규칙이 덜 적힌 것이다. 갈린 자리를 찾아 보태고 같아질 때까지 반복한다
  5. /revise-claude-md 로 오늘 정한 것이 빠짐없이 반영됐는지 확인한다

제출: 로직 문서 + 결과표 + CLAUDE.md + 재현 확인 기록 (전·후를 나란히)

이 주의 요점은 문법이 아니라 "규칙을 적으면 재현된다" 를 몸으로 겪는 것이다.
가정 과제: 자기 프로젝트 폴더에도 CLAUDE.md 를 만든다.
