방법 2 / 7

대표값: 어떻게 작동하나

$\bar{x} = \dfrac{1}{n}\sum_{i=1}^{n} x_i$   ·   중앙값 $= x_{((n+1)/2)}$ (크기순으로 세운 뒤)

평균은 무게중심

값 하나가 멀리 있으면 그쪽으로 끌려감

중앙값은 순위

얼마나 먼지는 보지 않고 몇 번째인지만 봄

→ 그래서 한쪽 꼬리가 긴 자료에서 평균 > 중앙값

방법 3 / 7

산포: 어떻게 작동하나

$s = \sqrt{\dfrac{1}{n}\sum (x_i - \bar{x})^2}$   ·   $\text{IQR} = Q_3 - Q_1$

  1. 평균에서 얼마나 떨어졌나 를 각 값마다 잼
  2. 제곱함 — 양쪽 방향을 같게 만들고 먼 값을 키움
  3. 평균 냄 — 그것이 분산
  4. 제곱근 — 원래 단위로 돌아옴

→ 표준편차는 제곱을 거치므로 먼 값 하나에 민감함. IQR 은 가운데 절반만 보므로 둔감함

방법 3 / 7

→ 양 끝의 몇 건이 범위를 혼자 정함. 퍼짐을 말할 때 범위보다 IQR 이 안전함

방법 4 / 7

박스플롯: 어떻게 작동하나

  1. 크기순으로 세움
  2. Q1 · 중앙값 · Q3 를 찾아 상자를 그림
  3. 울타리를 침 — Q1−1.5×IQR 과 Q3+1.5×IQR
  4. 수염은 울타리 안의 마지막 값까지만 뻗음
  5. 울타리 밖의 값은 점으로 따로 찍음

→ 1.5 는 약속된 관습이지 법칙이 아님. 「이상치」로 찍혔다고 잘못된 값은 아님

방법 5 / 7

산점도: 목적과 정의

두 변수를 가로·세로 축에 놓고 관측치 하나를 점 하나로 찍은 그림

점들이 어떤 모양을 이루는지로 함께 움직이는지를 봄

필요한 자료 — 연속변수 2개

→ 관계의 세기·방향·모양을 한 번에 봄. 직선인지 굽었는지, 이상치가 있는지도 여기서 드러남

방법 5 / 7

산점도: 어떻게 작동하나

점을 찍는 일은 간단함. 어려운 것은 무엇이 보이는지 읽는 일

  1. 방향 — 오른쪽 위로 가나, 아래로 가나
  2. 세기 — 선 주위에 촘촘한가, 흩어졌나
  3. 모양 — 직선인가, 굽었나
  4. 동떨어진 점 — 혼자 멀리 있는 것이 있나

→ 상관계수 하나로 줄이기 전에 반드시 그림을 먼저 봄. 굽은 관계는 계수가 0 에 가깝게 나옴 (9주차에서 다시)

방법 6 / 7

K-means 군집분석: 목적과 정의

여러 속성으로 잰 거리가 가까운 것끼리 미리 정한 개수 k 개의 묶음으로 나누는 일

맞힐 답이 없음. 자료 안에 어떤 유형이 있는지 스스로 찾음

필요한 자료 — 연속변수 여럿 · 묶음 개수 k

→ 6주차의 군집은 속성으로 묶음. 위치로 묶는 것은 7주차 DBSCAN 에서 다룸

방법 6 / 7

K-means: 어떻게 작동하나

  1. 표준화 — 단위가 다르면 큰 수가 거리를 독차지
  2. 중심 k 개를 놓음
  3. 배정 — 각 점을 가장 가까운 중심에
  4. 갱신 — 중심을 그 묶음의 평균으로 옮김
  5. 움직이지 않을 때까지 3·4 를 되풀이

→ 시작 위치가 답을 바꿈. 이 강의 스크립트는 서로 가장 먼 점부터 골라 난수를 쓰지 않음

배정 → 갱신 → 되풀이

방법 6 / 7

K-means: 적용 사례

17개 동을 거래건수와 ㎡당 중앙값으로 묶음

→ 군집 3 은 전부 「리」. 찾아낸 것은 유형이라기보다 신도시와 편입 읍면의 경계임

k = 3 은 팔꿈치에서 골랐음 — 34.0 → 19.2 → 4.4 → 3.4

방법 7 / 7

계층적 군집분석: 목적과 정의

가장 가까운 둘을 차례로 합쳐 나가 전체를 하나의 나무로 만드는 일

그 나무를 덴드로그램이라 함. 어느 높이에서 자르느냐로 묶음 개수가 정해짐

필요한 자료 — 연속변수 여럿. k 를 미리 정하지 않아도 됨

→ K-means 가 「몇 개로 나눌까」라면 계층군집은 「어떤 순서로 가까운가」를 보여 줌

방법 7 / 7

계층적 군집분석: 어떻게 작동하나

  1. 각자 하나의 묶음에서 시작함
  2. 모든 짝의 거리를 재 가장 가까운 둘을 합침
  3. 합친 묶음과 나머지의 거리를 다시 잼
  4. 하나가 남을 때까지 되풀이함

묶음끼리의 거리를 어떻게 재나

최단연결 가장 가까운 한 쌍 · 최장연결 가장 먼 한 쌍 · 평균연결 모든 쌍의 평균

→ 이 강의는 평균연결

→ 사슬처럼 늘어지는 것과 이상치에 덜 흔들림

계층적 군집분석: 적용 사례

평균연결로 합쳐 나감
