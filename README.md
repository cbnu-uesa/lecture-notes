# 강의노트

권규상(충북대) 학기별 강의노트. **HTML 슬라이드가 원본이고 PDF는 그 산출물이다.**
예전에는 PowerPoint로 만들어 PDF로 출력해 강의했다.

지금 두 과목 18개 강의가 모두 HTML로 되어 있고, PDF도 함께 빌드돼 있다.

---

## 빠르게 시작

```bash
_scripts/serve.sh          # → http://localhost:8080
```

브라우저에서 과목 → 강의를 고르면 슬라이드가 열린다. 좌우 화살표로 넘긴다.
**`file://` 로 직접 열지 않는다** — `course.json` 을 fetch 하지 못해 푸터와 표지 날짜가 빈다.

강의 중에 쓰는 것들:

| 키 | 동작 |
|---|---|
| `→` `←` | 다음 / 이전 (누적 공개 단계 포함) |
| `F` | 전체화면 |
| `S` | 발표자 화면 (노트·타이머) |
| `O` 또는 `Esc` | 전체 슬라이드 훑어보기 |
| 우하단 버튼 | 이 강의 PDF 내려받기 |

## 폴더 구조

```
200_education/
├── README.md              이 파일 — 무엇이 있고 어떻게 실행하는가
├── CLAUDE.md              Claude 에게 주는 작업 규칙
├── design.md              디자인 시스템 — 슬라이드 손대기 전 필독
├── index.html             전체 학기 허브
├── _shared/               전 학기 공용 — theme(CSS 4) · js · fonts · vendor
├── _templates/            lecture.html (슬라이드 뼈대) · dossier.md (판독물 규격)
├── _design/               디자인 카탈로그 미리보기 카드
├── _scripts/              아래 "명령어" 참조
└── <학기폴더>/
    ├── course.json        과목 메타 — 푸터·날짜·강의 목록의 유일한 출처
    ├── index.html         이 과목의 강의 목록
    ├── slides/            NN-핵심어.html          ← 원본
    ├── pdf/               NN-핵심어.pdf           ← 빌드 산출물
    ├── assets/            과목 전용 이미지
    ├── source/            비공개 — 원본 pptx, 교재 스캔, OCR, 판독물
    └── private/           비공개 — 시험지·성적·문제은행
```

과목명·학기·날짜를 슬라이드 HTML에 적지 않는다. 전부 `course.json` 에서 자동으로 들어간다.
표지 날짜는 파일명 앞 두 자리로 `lectures` 에서 제 강의를 찾아 채운다.

## 명령어

| 명령 | 하는 일 |
|---|---|
| `_scripts/serve.sh` | 로컬 미리보기 (8080). 강의할 때도 이걸로 연다 |
| `_scripts/check-figures.sh` | 그래프 자동 검사 — **PDF 뽑기 전 필수** |
| `_scripts/build-pdf.sh` | PDF 빌드. 인자 없으면 전체, 파일을 주면 그것만 |
| `_scripts/build-site.sh` | 배포용 `dist/` 생성 (화이트리스트 복사) |
| `_scripts/stage-design.sh` | 디자인 카탈로그 미리보기 (8090) |
| `_scripts/ocr-scan.sh <폴더>` | 교재 스캔 폴더를 OCR → 폴더 안 `_ocr.txt` |
| `_scripts/dossier-read.sh` | 교재 판독물 읽기 (8091) — 스캔 원본과 판독 텍스트를 나란히 |

PDF는 `npx decktape` 가 헤드리스 Chrome으로 만든다. 브라우저 인쇄 대화상자를 쓰지 않는다 —
환경마다 결과가 달라지기 때문이다. 처음 실행하면 decktape 를 내려받느라 시간이 걸린다.

`check-figures.sh` 는 눈으로 놓치기 쉬운 것을 잡는다: 좌표점이 곡선을 벗어났는지,
글자가 캔버스 밖으로 잘렸는지, **표·그림이 푸터를 넘었는지**, 뜻이 다른 곡선이 같은 색인지.
**문제가 0건이 될 때까지 PDF를 뽑지 않는다.**

## 새 강의 만들기

1. `_templates/lecture.html` 을 `<학기폴더>/slides/NN-핵심어.html` 로 복사한다. 빈 파일에서 쓰지 않는다.
2. `course.json` 의 `lectures` 에 강 번호·날짜·제목을 넣는다.
3. 슬라이드를 쓴다. 유형(T1~T11)과 색·치수는 `design.md`, 실물 예시는 `_design/slides/` 카드.
   개념 그래프는 `_shared/js/charts.js` 의 함수를 먼저 찾아 쓰고, 없으면 거기에 추가한다.
   **좌표를 손으로 찍지 않는다** — 비용함수·수요곡선 같은 관계식에서 유도한다.
4. `_scripts/serve.sh` 로 눈으로 확인한다.
5. `_scripts/check-figures.sh` 를 0건이 될 때까지 돌린다.
6. `_scripts/build-pdf.sh <파일>` 로 PDF를 뽑는다.

**새 학기를 열 때**는 `course.json` 만 만들면 빌드·검사 스크립트가 자동으로 인식한다.
수동 등록은 루트 `index.html` 의 `COURSES` 배열 한 곳뿐이고, 과목 `index.html` 은
기존 것을 그대로 복사하면 된다 (과목명이 하드코딩돼 있지 않다).

## 디자인

성격은 한 문장으로 **학술 저널의 편집 지면**이다. 크림슨 푸터바 없음, 제목은 명조,
표는 괘선 최소, 메인색 `#A02948`. 자세한 규범은 `design.md` 에 있고,
글로 적힌 규범을 눈으로 보는 판이 `_design/` 의 카탈로그 카드다
(`_scripts/stage-design.sh`).

테마 파일은 `tokens.css` → `cbnu.css` → `components.css` → `print.css` 넷뿐이고
읽는 순서가 곧 덮어쓰는 순서다. 테마 변종은 없다.

## 교재 판독물 (2학기)

교재 스캔을 판독한 결과를 `source/<장>/_dossier.md` 로 남긴다. 예전에는 슬라이드를
만들고 나면 버렸는데, 판독 비용이 큰 데다 강의 개정과 연구에 다시 쓸 수 있어서
파일로 보존한다. 지금 9개 장 231쪽이 들어 있다.

```bash
_scripts/dossier-read.sh    # → http://localhost:8091
```

쪽마다 **왼쪽에 스캔 원본, 오른쪽에 판독 텍스트**가 나란히 놓인다. 그림·사진·표는
스캔 이미지가 원본 그대로 보존하므로 텍스트 쪽에는 캡션·축 이름·인쇄된 숫자만 적는다
(그림의 뜻을 해석하지 않는다). 표는 숫자를 다시 쓰게 되므로 마크다운 표로도 옮긴다.
안 읽히는 자리는 지어내지 않고 `[판독불가]` 로 둔다 — 지금 두 쪽이 그렇고,
`private/스캔-재촬영-필요.md` 에 등재돼 있다.

읽기 화면 묶음은 Drive 밖 임시 폴더에 만들어지므로 동기화되지 않는다. 원본은 `.md` 파일이다.

## 공개 / 비공개

**학기 폴더에는 시험지·성적·채점표가 함께 들어 있다. 웹에 올라가면 사고다.**

| 폴더 | | 내용 |
|---|---|---|
| `slides/` `pdf/` `assets/` | 공개 | 강의노트와 그 산출물 |
| `source/` | **비공개** | 원본 pptx, 교재 스캔·OCR·판독물 |
| `private/` | **비공개** | 시험지, 성적·채점, 문제은행 |

두 겹으로 막혀 있다. `build-site.sh` 는 **화이트리스트** 방식이라
`slides/` `pdf/` `assets/` `index.html` `course.json` `_shared/` 만 담는다 —
제외 목록을 관리하지 않으므로 새 폴더가 생겨도 저절로 새지 않는다.
그리고 `.gitignore` 가 `*/private/` 와 `*/source/` 를 버전관리에서 뺀다.

교재 판독물은 원문을 그대로 옮긴 것이라 **웹에 올리지 않는다**
(판권면에 "무단전재와 복제를 금합니다"). 강의노트를 만드는 입력으로만 쓰고,
슬라이드에는 소화한 개념과 재작도한 도식만 넣는다.

## 작업 환경에 관한 주의

- **작업 폴더가 Google Drive 동기화 대상이다.** 이 폴더에서 `npm install` 을 하지 않는다
  (`node_modules` 가 생기면 동기화가 망가진다). 일회성 도구는 `npx` 로 실행해
  캐시가 `~/.npm`(Drive 밖)에 남게 한다. 임시 파일도 시스템 임시 디렉터리에 만든다.
- **셸에서 한글 파일명을 glob으로 매칭하지 않는다.** macOS는 파일명을 NFD로 저장하는데
  스크립트에 적는 한글 리터럴은 NFC라서 `*학기_*/` 같은 패턴이 조용히 아무것도 못 잡는다.
  학기 폴더는 이름이 아니라 **`course.json` 이 있는지**로 찾는다.
- 배포는 아직 설정하지 않았다. `build-site.sh` 가 `dist/` 를 만드는 데까지만 되어 있다.
